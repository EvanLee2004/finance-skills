## 一、进仓库（push 到 GitHub / Gitee）

| 进 | 说明 |
|---|---|
| `skills/<id>/SKILL.md` | 技能本体（agent 读的作业规程） |
| `skills/<id>/scripts/*.py` | 确定性脚本（金额只由它算） |
| `skills/<id>/tests/*.py` | 回归测试（**只放合成数据或造数据的代码**） |
| `skills/<id>/references/*.md` | SOP、数据契约、话术、变更说明 |
| `skills/<id>/config/*.md` `.json` | 会变的业务规则、列名别名、维护表 |
| `skills/<id>/README.md` | 业务讲解（照 `技能README模板.md`） |
| `README.md` `SOURCE.md` `docs/` | 仓库总览、分发流程、规范 |
| `config/*.xlsx` **例外** | 仅**可长期维护的配置模板**（如销售组织架构），且**不含真实金额/客户明细** |

## 二、不进仓库（留本地）

| 不进 | 为什么 | 放哪 |
|---|---|---|
| **真实 xlsx / xls / csv / pdf** | 含客户名、金额、身份证号 | 各项目 `测试数据/`（在本仓之外） |
| **`skills/*/工作区/**`** | 运行产物、她的表副本、备份、日清 | 本机，随用随清 |
| **需求收集过程**（录音、逐字稿、千问转录、需求确认 docx） | 是**项目**资产不是**技能**资产；含同事原话与内部口径 | `项目/长期项目/<项目名>/原始素材/` |
| **给同事的成品 Word / 使用手册 docx** | 分发件不是源码；改版频繁 | `财务部skills/发布/`、各技能家 `方案与文档/` |
| **凭据**：`config.local.json`、`.env`、`md_pss_id`、任何账号密码 | 泄露即事故 | 只在本机；运行时输入 |
| **内网地址与账号可见性结论** | 内网信息不外传 | 项目 Agent.md / progress.md |
| **技能包 zip** | 2026-07-25 起 git 即分发，zip 仅极端备用 | `财务部skills/归档/` |

## 三、为什么"需求收集"不进技能仓（明昊 2026-07-25 明确）

一个技能的**开发过程**和**技能本身**是两码事：

- **技能仓**回答：这技能能干吗、怎么跑、口径是什么 → **给用它的人和 agent 看**
- **项目文件夹**回答：这需求怎么来的、她原话说了啥、我们试过哪些方案、踩过哪些坑 → **给我们自己看**

以 `ar-hexiao-daily` 为例：

| 东西 | 去哪 |
|---|---|
| SKILL.md / scripts / config / README / 变更说明 | ✅ `finance-skills/skills/ar-hexiao-daily/` |
| 明妹录屏、逐字稿、需求确认 docx、全流程说明、模块划分建议 | ❌ 留 `项目/长期项目/应收核销自动化（李明妹）/` |
| 她的真实盈亏表、到账流转单、金标测试数据 | ❌ 留该项目 `测试数据/`（本仓之外，天然不进库） |
| 给她的《使用说明》 | ✅ 放 `references/使用说明_给明妹.md`（**这是技能的一部分**，同事装完就该看到） |

**判据**：这份东西，**别的公司/别的同事拿到技能包后需不需要**？
需要 → 进仓库；只有我们做这个项目时才用得上 → 留项目文件夹。

## 四、提交前自检（每次 push 都过一遍）

```bash
# ① 看清楚这次要提交什么
git status --short

# ② 扫敏感内容（真实单号/内网 IP/密码）
git diff --cached -U0 | grep -Ei "192\.168|password *=|token|身份证|SOD2[0-9]{6}" | head

# ③ 确认没有真实表混进来
git diff --cached --name-only | grep -Ei "\.(xlsx|xls|csv|pdf)$"
```

第 ③ 步**有输出就停下**——除非确认是 `config/` 下的配置模板且不含真实明细。

> 更完整的发布安全规矩见根 `Agent.md` 维护规则第 10 条与 `SOURCE.md`。

## 五、加新技能时怎么摆

```
finance-skills/skills/<id>/          ← 进仓库：源码四件套 + README
财务部skills/技能/<中文名>/           ← 不进仓库：本地资料家
├── Agent.md          （这技能的本地记录）
├── 原始素材/          （录音、纪要、她给的初始文件）
├── 方案与文档/        （对内方案 + 给同事的 Word）
└── 测试数据/          （真实数据，回归用）
```

两边**平行**，不嵌套——源码仓要能整个 push，本地资料要能随便放真实数据。
