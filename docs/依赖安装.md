# 依赖怎么装（给 agent · 不是技能）

缺库时在**当前业务技能里当场装**。不要另开「环境管家」，不要停下来让她「配环境」。

镜像顺序写死：**清华 → 阿里 → 中科大 → 默认源**。

```bash
python3 -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <包>
```

清华失败换 `-i https://mirrors.aliyun.com/pypi/simple`；再失败换 `-i https://pypi.mirrors.ustc.edu.cn/simple`；镜像都失败再去掉 `-i`。

import 名对照：`docx` → `python-docx`；`pptx` → `python-pptx`；`PIL` → `Pillow`。不要 pip `validators` / `helpers` / `office`（技能自带模块）。

---

## 一把全装（新机器）

```bash
python3 -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pandas openpyxl xlrd pypdf pdfplumber pdf2image python-docx python-pptx markitdown lxml defusedxml Pillow requests playwright
python3 -m playwright install chromium
```

---

## 各技能常用库

| import 名 | pip 包名 | 谁要用 |
|-----------|----------|--------|
| `pandas` | pandas | 应收合并 / 按销售拆 / 劳务核对 / xlsx |
| `openpyxl` | openpyxl | 多数 Excel 技能 |
| `xlrd` | xlrd | 核销日清、部门费用（老 `.xls`） |
| `pypdf` | pypdf | pdf |
| `pdfplumber` | pdfplumber | pdf / 代扣代缴改名 |
| `pdf2image` | pdf2image | pdf 转图（还要系统 poppler） |
| `docx` | **python-docx** | docx |
| `pptx` | **python-pptx** | pptx |
| `PIL` | **Pillow** | pdf / pptx |
| `requests` | requests | 金蝶入账 / 损益表 / 九点下单 |
| `playwright` | playwright | 核销 / 九点下单 / 损益表网页引出 |

OCR / 造 PDF 才要：`pytesseract`、`reportlab`、`pypdfium2`。

## 系统工具（不是 pip）

| 工具 | 缺了会怎样 | Windows | Mac |
|------|------------|---------|-----|
| LibreOffice（`soffice`） | xlsx 重算 / pptx 缩略图 / docx 接受修订不可用；基本读写仍可 | `winget install TheDocumentFoundation.LibreOffice` 或清华 LibreOffice 镜像 | `brew install --cask libreoffice` |
| poppler（`pdftoppm`） | pdf2image 转图失败 | `scoop install poppler` | `brew install poppler` |
| tesseract | OCR 失败 | `scoop install tesseract` | `brew install tesseract tesseract-lang` |

Python 建议 ≥ 3.10。office 可选校验脚本用了 `match`，3.9 会 SyntaxError；财务脚本核心读写不受影响。
