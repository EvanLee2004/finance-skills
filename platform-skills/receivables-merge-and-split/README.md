# 应收账款合并与销售拆分

一次上传材料后选择模式：

- `仅合并`：应收 all 和领导部分版。
- `合并并按销售拆分`：应收 all、领导部分版和销售人员工作簿 ZIP。
- `已有应收 all 直接拆分`：销售人员工作簿 ZIP。

合并产生的应收 all 会在同一次任务中直接传给拆分脚本，使用者不需要重复下载和上传。原始文件不会被覆盖，拆分结果必须通过行数对账。

合并结果的 `透视汇总` 是原生可刷新的数据透视表，数据源绑定 `主表` 的 `A1:Q1048576` 范围。向 `主表` 末尾追加新行后，在透视表中执行刷新即可更新。合并总表保留 `主表`、`透视汇总`、`催收参考`；领导部分版保留 `主表` 与 `透视汇总`，不附加诊断工作表或静态备份。销售人员合计及各销售下的客户均按应收金额从大到小排序，排序规则保存在原生透视字段中；原生透视生成失败时任务报错，不交付静态替代品。


`催收参考` 从主表逐行筛选结算阶段不包含 `已回款` 的记录，空白阶段也保留；输出 `销售`、`公司名称`、`金额` 三列，对应主表销售人员、客户名称、应收金额，先按销售人员与客户名称分组合计应收金额，再剔除合计金额小于100,000元的组（等于100,000元保留），最后按合计金额降序，同额保持各组首次出现顺序。同一客户属于不同销售时分别保留。无符合记录时保留表头。

催收参考另排除销售人员为 `梁玲玲-高美杰`、`于占国-高美杰`、`史立云` 的记录（比较前去除名字两端空白）；主表与透视汇总保留这些记录。

拆分兼容合并总表的短表头 `框架合同PO记录`、`客户确认` 及原模板完整表头，按列名保留两列原值；调整输入列顺序不影响对应字段。
