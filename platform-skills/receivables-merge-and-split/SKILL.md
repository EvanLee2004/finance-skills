# 应收账款合并与销售拆分

本 Skill 把应收合并和按销售拆分放进一次任务。合并完成后，生成的应收 all 在本地任务目录直接传给拆分脚本，不需要再次上传。

## 三种模式

- `仅合并`：本期源台账加可选上一版应收 all，输出应收 all 和领导部分版。
- `合并并按销售拆分`：先合并，再按销售人员生成 ZIP，是日常默认模式。
- `已有应收 all 直接拆分`：已有整理好的应收 all 直接生成销售人员工作簿 ZIP。

合并继续执行原有的分年合并、账龄、回填、销售归属、老坏账结转、删小额、复核和透视汇总。拆分继续执行销售分组、坏账桶和 GM 订单处理，并核对输入行数与分流行数。

## S8 透视汇总

合并结果中的 `透视汇总` 使用原生 Excel 数据透视表，按 `销售人员` → `客户名称` 汇总 `应收金额`，初始显示销售人员小计，客户明细保持折叠。透视缓存直接绑定 `主表` 的 `A1:Q1048576` 范围；在 `主表` 末尾追加新行后，打开 `透视汇总` 执行数据刷新即可纳入新行。原生透视表生成成功时，`透视汇总_静态备份` 保留本次生成时的静态汇总供核对；生成失败时保留原静态汇总并记录告警。

原始文件只读。关键列无法识别、销售归属存疑或拆分对账不平时，不静默猜测或丢行。

配置位于 `config/`，合并说明位于 `references/`；变化的业务口径改配置，不改确定性处理脚本。
