# 月度损益表 / 科目余额表

这就是把**金蝶星辰**里有账的主体，按斯佳版式抄进一张 Excel：**只有** `损益表` 和 `利润表`。左列公司本期借贷，右列部门核算，再加利润表本月/上月。跟用友部门费用归集不是一回事。

发生额由 `scripts/convert.py` 从金蝶引出/API 读出来再写进格子；合计/核对/父行是 Excel 公式。

## 启动时说

- **推荐**：月度损益表
- 也可：科目余额表 / 出本月损益表 / 损益表利润表 / 部门科目余额表 / 跑斯佳那张表 / 金蝶损益表

## 0. 她说什么就做什么

| 她说 | 做 |
|------|----|
| 月度损益表 / 科目余额表 / 出本月损益表 / 损益表利润表 / 部门科目余额表 / 跑斯佳那张表 / 金蝶损益表 | 调 `convert.py`。跑完先读运行报告：有 `ask=` 原样问；`利润表缺源` 不是无也要原样问；`核对非0其它` 必须是「无」 |
| 没给文件夹 | **不要加 `--input-dir`**。有完整材料夹（如本机 `工作区/全源_202608`）就用它；没有就落到当天桌面 `月度损益表_YYYYMMDD/`，API/网页往那里写。桌面 `月度损益表_*/引出/` 里 `hq.xlsx`/`wh.xlsx`/`dept.xlsx` 是旧草稿，禁止当源 |
| 给了山东/四川/济南代账利润表 | `--offline-xlsx` 各指一份，或放进她打开的文件夹 / 当天桌面夹。技能仓里没有这三张。**不要**把她做好的损益表当源 |
| 给了职工薪酬台账 / 损益表取数 | `--payroll-xlsx` 指文件，或放进同一文件夹。证件号行跳过，其余照加。文化/上海没有星辰引出时台账补工资社保左右列 |
| 没给这三家利润表 | 先出能出的表，把运行报告里的 `ask=` **原样问她** |
| 开放平台 API 失败 / 没有应用号又没有总部引出 / 网页账密没有或登录引出失败 / 当前号打不开利润表 | **不出表**。运行报告 `产物=未生成`、`status=login_blocked`，把 `ask=` **原样问她**。禁止说「月度损益表已出」 |
| 她说这三家先不处理 | 加 `--skip-offline`，这三列留空 |
| 部门费用归集 / 用友按人拆 | **不是本技能**（那是用友另一张表），转 `dept-expense-alloc` |
| 序时账入金蝶 / 湖南分抄作业 | 转 `kingdee-gl-import` |

没说月份 → 上一个已过完的公历月（9 月 1 日出 8 月）。

## 0.4 每次开工先预检（通了再取数）

能自己从金蝶取的**不问她**。先确认取数是技能问题还是真缺材料/真登不上：

1. 本机 `xingchen.local.json` 能登录工作台；`kingdee.local.json` 能打总部只读 API。登不上 / API 失败：**不出表**，`ask=` 问账密或权限。不要把切账/选期写错当成她没权限。
2. 扫她给的文件夹或当天桌面夹：当期代账三家、薪酬台账（假数/明昊测试不喂）、不要把她做好的损益表当源。技能仓更新后也没有代账，她必须自己把三张 `.xls` 放进夹子。
3. 星辰五本：当期科目余额/利润表 + **上月利润表**，缺了自己网页引出或 API 落 Excel。总部 API 已经落了科目/核算就不要再切总部网页。湖南分/子不拉核算项目（办公费/房租走本公司规则）。上月利润表不问她要。
4. 山东/四川/济南只有代账小企业利润表。**当期没有**：这三列空着，先出别的，`ask=` 要当期代账。**上月没有**：利润表上月这三列空着，先出别的，告诉她有就补、没有就先这样。
5. 真·薪酬没有：工资叶子右列空着问拆分表，不要停整张表。

## 0.5 红线

1. **读金蝶引出、写斯佳 Excel = `scripts/convert.py` 的活。** 必须跑这条脚本。禁止在对话里 `python -c` / 自写 `import openpyxl` 把引出或产物格子打印出来（金额会进日志）。
2. 对话只报：期间、有源/缺源账套短名、利润表缺源、利润表上月缺线下、未映射部门个数、核对非 0 的绿行/父行/其它编码、产物路径。禁止金额、口令、Client Secret。
3. 密钥已在本机就直接用，不要问她填、不要去开放平台。网页登录读 `~/.config/finance/xingchen.local.json`（没有则问一次怎么填）。开放平台用 `kingdee.local.json`。禁止读 `zhiyun.local.json`。禁止点引入/审核/过账/购买/解绑总部/新增生成利润表。
4. 山东/四川/济南无星辰账：源是代账利润表（本月金额）。损益表是产物，禁止倒填。缺表就问；她说先不处理则空列，不是 0。未映射部门只进运行报告。文化和上海「本公司」按 `config/本公司规则.json`，禁止写进全局部门映射、禁止整账视听。核算项目没有费用时用科目余额填右列。
5. **右列先信核算项目余额表（部门）**。总部有引出就用引出，不要用凭证辅助凑。Downloads 里的 `核算项目余额表*.xlsx` 也能认。工资/社保/公积金：有职工薪酬台账就按组织架构拆到叶子（渠道开发中心进研发 5503；本地化销售第 1 列、成本第 2 列；四川进财务中心，不进四川分公司列）。没台账且核算项目也没挂部门 → 右列空着，运行报告 `ask=` 原样问她，禁止倒填损益表、禁止按人数猜。文化和上海的本公司工资在有台账后改走台账，差旅/房租仍走本公司规则。文化和上海 5101 本公司不进视听/本地化，残差进营销总监及助理；总部收入里挂「济南分公司」的改挂渠道开发中心。投资收益叶子无部门的进总经办。损益发生额与核对同口径（收入看贷方、费用看借方）；总部有科目余额引出时左列用引出，不用凭证结转双边。斯佳指定整笔归集（`config/残差归集.json`，覆盖核算项目拆分）：折旧费/无形资产摊销→运营保障中心；税金及附加树（5402）和财务费用树（5504）→财务中心；540103 翻译语言服务→项目总监及助理。
6. 湖南分抄进金蝶之后必须**重新引出**科目余额/核算项目/利润表。入账前的空引出当没源。总部房租摘要含「深圳」进广东分公司、「长沙」进湖南分公司；没有摘要源则留运保，禁止残差一律进广东。
7. 真实引出不进 git。不要对系统 Python `pip install`。不要读「内网勿外传」口令 md，不要复用 Chrome 配置目录。

## 0.6 总流程（先源 Excel，再核算）

Agent 按这个顺序做，不要半套源就出损益表：

1. **总部 API → Excel**：`scripts/dump_api_excel.py --period 202608 --out-dir <材料夹>/API`。科目余额 OpenAPI 400 时脚本用凭证汇总，一样落成表。只报文件名和占用个数。
2. **网页 Playwright → Excel**：文化/上海/湖南分/湖南子的科目余额、核算项目、利润表查询页（`gl_profitsheet1`，本月金额）。总部网页科目/核算缺了，点名 `jiagu` 再拉；有网页文件就优先，API 那份只对照、不叠两遍。
3. **斯佳给的源**（录音 + 技能家口径）：山东/四川/济南只有**代账小企业利润表**（会小企 / 本月金额），不是金蝶科目余额，也不是做好的损益表。放进同一材料夹。她交的 `损益类部门科目余额表` 是**答案金标**，只对照，不当源。文件名带假数/明昊测试的薪酬台账不喂。
4. **核算**：材料夹已齐后再跑下面的 `convert.py`。右列、本公司、残差、房租摘要、济南减法都走本地 `config/`，禁止改数凑平。

`convert.py` 自己也会先把总部 API 落到材料夹 `API/`，再补网页缺口，再拼表。同事说「月度损益表」时仍只跑这一条。

## 1. 就跑这一条

她没给文件夹时**原样**跑（把期间换成她说的，没说用 `202608`；日期文件夹用今天）：

```bash
python3 "<本skill目录>/scripts/convert.py" --period 202608
```

没给 `--out` 时默认写到桌面 `月度损益表_YYYYMMDD/月度损益表_<期间>.xlsx`。没给 `--input-dir` 且本机没有完整材料夹时，源也落到这个当天桌面夹，不要写进 skill 仓。她给了代账利润表就加 `--offline-xlsx`（可多次）。薪酬台账放进文件夹或加 `--payroll-xlsx`。当前工作目录里已经有代账/取数/引出、且不在 `finance-skills/skills` 树里时，**就用当前目录**，不要再叠一份技能家引出（同名表加两遍核对会炸）。文件名带假数/明昊测试的台账不当薪酬源。科目余额/核算项目也必须是当期；9 期文件不当 8 月源。科目余额要从–至两格都改成当期，并勾「显示所有科目」（结转后 5 开头期末常为 0，不勾会整表消失）。

- **不要**加 `--no-api`（测试才加）。**不要**加 `--input-dir`，除非她亲口给了一个文件夹。
- 跑完**先读运行报告**。`产物=未生成` 或 `status=login_blocked`：只问 `ask=`，禁止说表已出、禁止拿旧表当这次结果。有 `ask=`：原样问她，不要当做出表成功、不要拿损益表成品凑数。
- 薪酬台账里证件号/插行：脚本自己跳过那一行，能加的行继续加，**不要停下来让她改 Excel**，禁止打开台账点人名或行号。
- 文件名带「假数 / 明昊测试 / 掏空」的台账不当薪酬源，不要改名硬喂。
- **核对列**：Excel 里 0 显示为 `-`。`核对非0其它` 必须是「无」。绿行、它们的父行、未映射部门可以非 0。不要为了对而改数或猜列。
- 系统 python 缺库时脚本会自己切仓内 `.venv`。
- 对话只抄报告第一段（期间/有源/缺源/个数/路径）和 `ask=`。不要把 xlsx 格子打进对话。
- 文化/上海/湖南分/湖南子：脚本先扫技能家/桌面引出。科目余额或核算项目缺了、或利润表没有**当期**文件时，会跑 `xingchen_export.py`（账密读 `xingchen.local.json`）。利润表走菜单 **利润表查询页**（`gl_profitsheet1`）：会计期间选当期（星辰是 `2026年08期` 这种补零，点格子里的「8期」，不要停在 9 期）→ 查询/刷新 → 看本月金额 → 工具栏引出 → 对话框再点引出。不要走「个别报表」列表。过期的 7 期文件只进上月列，**不挡**当期拉取，禁止把 7 期当本月。当期齐了还要再拉**上月**利润表查询页（同一套选期，换成上期）。禁止点新增/生成/审核/上报。`--no-api` 测试才加，不开浏览器。本机没账密、登录失败、API 失败：**不出表**，`ask=` 原样问。不要把列表页没权限写成整本利润表都没有。

## 2. 收尾（照抄）

> 月度损益表已出，期间 YYYYMM。有源账套：…；缺源：…。利润表缺源：…。利润表上月缺线下：…。未映射部门 N 个。核对非 0 的科目编码 M 个。表在 \<路径\>，运行报告在同目录。请打开看两个 sheet，不要改数凑平。

只报编码：绿行 / 父行 / 未映射 / 其它。其它必须无。未映射是对不上的部门，不要猜进某一列。不要问「要不要改数」。有 `ask=` 或利润表缺源不是无时先问 `ask=`。利润表上月缺线下不是无：告诉她这三列先空着，有上月代账再补，没有就先这样。`产物=未生成` 时不要说表已出。
