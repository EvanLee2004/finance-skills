# 月度损益表 / 科目余额表

这就是把**金蝶星辰**里有账的主体，按斯佳版式抄进一张 Excel：**只有** `损益表` 和 `利润表`。左列公司本期借贷，右列部门核算，再加利润表本月/上月。跟用友部门费用归集不是一回事。

发生额由 `scripts/convert.py` 从金蝶引出/API 读出来再写进格子；合计/核对/父行是 Excel 公式。

## 启动时说

- **推荐**：月度损益表
- 也可：科目余额表 / 出本月损益表 / 损益表利润表 / 部门科目余额表 / 跑斯佳那张表 / 金蝶损益表

## 0. 她说什么就做什么

| 她说 | 做 |
|------|----|
| 月度损益表 / 科目余额表 / 出本月损益表 / 损益表利润表 / 部门科目余额表 / 跑斯佳那张表 / 金蝶损益表 | **立刻**调 `convert.py`（它会读金蝶引出并写表） |
| 没给文件夹 | **不要加 `--input-dir`**。脚本自己扫技能家引出。桌面 `月度损益表_*/引出/` 里 `hq.xlsx`/`wh.xlsx`/`dept.xlsx` 是旧草稿，禁止当源 |
| 给了山东/四川/济南代账利润表 | `--offline-xlsx` 各指一份，或放进文件夹。**不要**把她做好的损益表当源 |
| 没给这三家利润表 | 先出能出的表，把运行报告里的 `ask=` **原样问她** |
| 她说这三家先不处理 | 加 `--skip-offline`，这三列留空 |
| 部门费用归集 / 用友按人拆 | **不是本技能**（那是用友另一张表），转 `dept-expense-alloc` |
| 序时账入金蝶 / 湖南分抄作业 | 转 `kingdee-gl-import` |

没说月份 → 上一个已过完的公历月（9 月 1 日出 8 月）。

## 0.5 红线

1. **读金蝶引出、写斯佳 Excel = `scripts/convert.py` 的活。** 必须跑这条脚本。禁止在对话里 `python -c` / 自写 `import openpyxl` 把引出或产物格子打印出来（金额会进日志）。
2. 对话只报：期间、有源/缺源账套短名、未映射部门个数、核对非 0 的科目编码个数、产物路径。禁止金额、口令、Client Secret。
3. 密钥已在本机就直接用，不要问她填、不要去开放平台。禁止点引入/审核/过账/购买/解绑总部/新增生成利润表。
4. 山东/四川/济南无星辰账：源是代账利润表（本月金额）。损益表是产物，禁止倒填。缺表就问；她说先不处理则空列，不是 0。未映射部门只进运行报告。文化和上海「本公司」按 `config/本公司规则.json`，禁止写进全局部门映射、禁止整账视听。核算项目没有费用时用科目余额填右列。
5. **右列只信核算项目余额表（部门）**。总部有引出就用引出，不要用凭证辅助凑。Downloads 里的 `核算项目余额表*.xlsx` 也能认。工资/社保在核算项目和凭证里都没挂部门 → 右列空着，运行报告 `ask=` 原样问她要拆分或手填，禁止用她做好的损益表倒填，禁止按人数猜。
6. 湖南分抄进金蝶之后必须**重新引出**科目余额/核算项目/利润表。入账前的空引出当没源。广东房租记在运营保障中心，没有广东档案就空着。
5. 真实引出不进 git。不要对系统 Python `pip install`。

## 1. 就跑这一条

她没给文件夹时**原样**跑（把期间换成她说的，没说用 `202608`；日期文件夹用今天）：

```bash
python3 "<本skill目录>/scripts/convert.py" --period 202608
```

没给 `--out` 时默认写到桌面 `月度损益表_YYYYMMDD/月度损益表_<期间>.xlsx`。她给了代账利润表就加 `--offline-xlsx`（可多次）。

- **不要**加 `--no-api`（测试才加）。**不要**加 `--input-dir`，除非她亲口给了一个文件夹。
- 运行报告若有 `ask=`：原样问她，不要拿损益表成品凑数。
- 系统 python 缺库时脚本会自己切仓内 `.venv`。
- 跑完读同目录 `*_运行报告.txt` 的**第一段**（期间/有源/缺源/个数/路径），照抄到对话。不要把 xlsx 格子打进对话。
- 文化/上海/湖南分/湖南子的引出已在技能家；脚本会读这些金蝶引出。只有技能家也没有、桌面也没有时，才用已登录同事号跑 `xingchen_export.py`。8 期利润表没有就留空，禁止把 7 期当本月，禁止点新增/审核/上报。

## 2. 收尾（照抄）

> 月度损益表已出，期间 YYYYMM。有源账套：…；缺源：…。未映射部门 N 个。核对非 0 的科目编码 M 个。表在 \<路径\>，运行报告在同目录。请打开看两个 sheet，不要改数凑平。

有核对非 0：只报科目编码个数。不要问「要不要改数」。

## 3. 会变的在哪

| 文件 | 改什么 |
|------|--------|
| `config/账套清单.json` | 8 家顺序、5 本星辰账 |
| `config/线下利润表.json` | 山东/四川/济南代账利润表怎么进损益表/利润表 |
| `config/本公司规则.json` | 文化/上海「本公司」按科目进哪一列；核算项目没费用时从科目余额补 |
| `config/部门名映射.json` | 金蝶档案名 → Excel 列（大客户→KA、产品部→渠道开发中心）；不要把本公司写进来 |
| `config/版式.json` | 科目树、列、冻结（无金额） |
| `config/引出列名.json` | 引出表头别名 |
| `config/科目名同义.json` | 引出科目名 → 版式名 |
| 本机 `kingdee.local.json` | 连接器；不进仓 |

## 防漏

| 用户说法 | 用哪个 |
|----------|--------|
| 月度损益表 / 科目余额表 / 跑斯佳那张表（金蝶） | **本技能** |
| 部门费用归集 / 用友按人拆 | `dept-expense-alloc`（用友，不是这张金蝶表） |
| 销项/付款/收款入金蝶 | `kingdee-posting` |
| 序时账入金蝶 / 湖南分抄作业 | `kingdee-gl-import` |
