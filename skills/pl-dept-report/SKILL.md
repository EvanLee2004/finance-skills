# 月度损益表 / 科目余额表

同事说人话出一张 Excel：**只有** `损益表` 和 `利润表`。发生额由 `scripts/convert.py` 写；合计/核对/父行是 Excel 公式。

## 启动时说

- **推荐**：月度损益表
- 也可：科目余额表 / 出本月损益表 / 损益表利润表 / 部门科目余额表 / 跑斯佳那张表 / 金蝶损益表

## 0. 她说什么就做什么

| 她说 | 做 |
|------|----|
| 月度损益表 / 科目余额表 / 出本月损益表 / 损益表利润表 / 部门科目余额表 / 跑斯佳那张表 / 金蝶损益表 | **立刻**调下面那条 `convert.py`，不要先 glob、不要先读 xlsx |
| 没给文件夹 | **不要加 `--input-dir`**。脚本自己扫技能家引出。桌面 `月度损益表_*/引出/` 里 `hq.xlsx`/`wh.xlsx`/`dept.xlsx` 是旧草稿，禁止当源 |
| 部门费用归集 / 用友按人拆 | **不是本技能**，转 `dept-expense-alloc` |

没说月份 → 上一个已过完的公历月（9 月 1 日出 8 月）。

## 0.5 红线

1. **只准**调本技能 `scripts/convert.py`（缺环境再说「配下环境」）。**禁止** `python -c`、`import openpyxl`、自写脚本读引出/产物/Downloads。禁止把格子打印到对话。
2. 对话只报：期间、有源/缺源账套短名、未映射部门个数、核对非 0 的科目编码个数、产物路径。禁止金额、口令、Client Secret。
3. 密钥已在本机就直接用，不要问她填、不要去开放平台。禁止点引入/审核/过账/购买/解绑总部/新增生成利润表。
4. 山东/四川/济南无星辰账：单元格留空，不是 0。未映射部门只进运行报告。
5. 真实引出不进 git。不要对系统 Python `pip install`。

## 1. 就跑这一条

她没给文件夹时**原样**跑（把期间换成她说的，没说用 `202608`；日期文件夹用今天）：

```bash
python3 "<本skill目录>/scripts/convert.py" --period 202608 --out "$HOME/Desktop/月度损益表_20260901/月度损益表_202608.xlsx"
```

- **不要**加 `--no-api`（测试才加）。**不要**加 `--input-dir`，除非她亲口给了一个文件夹。
- 系统 python 缺库时脚本会自己切仓内 `.venv`。
- 跑完读同目录 `*_运行报告.txt` 的**第一段**（期间/有源/缺源/个数/路径），照抄到对话。不要打开 xlsx。
- 文化/上海/湖南分/湖南子的引出已在技能家；脚本会找到。只有技能家也没有、桌面也没有时，才用已登录斯佳号跑 `xingchen_export.py`（不要新开未登录 Playwright）。8 期利润表没有就留空，禁止把 7 期当本月，禁止点新增/审核/上报。

## 2. 收尾（照抄）

> 月度损益表已出，期间 YYYYMM。有源账套：…；缺源：…。未映射部门 N 个。核对非 0 的科目编码 M 个。表在 \<路径\>，运行报告在同目录。请打开看两个 sheet，不要改数凑平。

有核对非 0：只报科目编码个数。不要问「要不要改数」。

## 3. 会变的在哪

| 文件 | 改什么 |
|------|--------|
| `config/账套清单.json` | 8 家顺序、5 本星辰账 |
| `config/部门名映射.json` | 金蝶档案名 → Excel 列（大客户→KA） |
| `config/版式.json` | 科目树、列、冻结（无金额） |
| `config/引出列名.json` | 引出表头别名 |
| `config/科目名同义.json` | 引出科目名 → 版式名 |
| 本机 `kingdee.local.json` | 连接器；不进仓 |
