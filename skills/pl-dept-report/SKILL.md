# 月度损益表 / 科目余额表

这就是把**金蝶星辰**里有账的主体，按斯佳版式抄进一张 Excel：**只有** `损益表` 和 `利润表`。左列公司本期借贷，右列部门核算，再加利润表本月/上月。跟用友部门费用归集不是一回事。

发生额由 `scripts/convert.py` 从金蝶引出/API 读出来再写进格子；合计/核对/右列父行是 Excel 公式。左列父行：总部抄金蝶（斯佳金标 VLOOKUP），其余七家=子行 SUM 公式（斯佳 2026-09-14 拍），所以非总部「父行核对=子行核对合计」恒成立。金蝶只给父级整笔、没叶子的发生额会被公式盖掉，运行报告 `父行发生额未落叶子=` 会点名并 `ask=`。

## 启动时说

- **推荐**：月度损益表
- 也可：科目余额表 / 出本月损益表 / 损益表利润表 / 部门科目余额表 / 跑斯佳那张表 / 金蝶损益表

## 0.4 每次开工先预检（通了再取数）

能自己从金蝶取的**不问她**。先确认取数是技能问题还是真缺材料/真登不上：

1. 本机 `xingchen.local.json` 能登录工作台；`kingdee.local.json` 能打总部只读 API。登不上 / API 失败：**不出表**，`ask=` 问账密或权限。不要把切账/选期写错当成她没权限。
2. 扫她给的文件夹或当天桌面夹：当期代账三家、薪酬台账（假数/明昊测试不喂）、不要把她做好的损益表当源。技能仓更新后也没有代账，她必须自己把三张 `.xls` 放进夹子。
3. 星辰五本：当期科目余额/利润表 + **上月利润表**，缺了自己网页引出或 API 落 Excel。总部 API 已经落了科目/核算就不要再切总部网页。湖南分/子不拉核算项目（办公费/房租走本公司规则）。上月利润表不问她要。
4. 山东/四川/济南只有代账小企业利润表。**当期没有**：这三列空着，先出别的，`ask=` 要当期代账。**上月没有**：利润表上月这三列空着，先出别的，告诉她有就补、没有就先这样。
5. 真·薪酬没有：工资叶子右列空着问拆分表，不要停整张表。

1. **读金蝶引出、写斯佳 Excel = `scripts/convert.py` 的活。** 必须跑这条脚本。禁止在对话里 `python -c` / 自写 `import openpyxl` 把引出或产物格子打印出来（金额会进日志）。
2. 对话只报：期间、材料夹名、有源/缺源账套短名、利润表缺源、利润表上月缺线下、未映射部门个数、核对非 0 的绿行/父行/其它编码、产物路径。禁止金额、口令、Client Secret。材料夹名要对她说出来，免得本机误吃到别人的「全源」夹。
3. 密钥已在本机就直接用，不要问她填、不要去开放平台。网页登录读 `~/.config/finance/xingchen.local.json`（没有则问一次怎么填）。开放平台用 `kingdee.local.json`。禁止读 `zhiyun.local.json`。禁止点引入/审核/过账/购买/解绑总部/新增生成利润表。
4. 山东/四川/济南无星辰账：源是代账利润表（本月金额）。损益表是产物，禁止倒填。缺表就问；她说先不处理则空列，不是 0。未映射部门只进运行报告。文化和上海「本公司」按 `config/本公司规则.json`，禁止写进全局部门映射、禁止整账视听。核算项目没有费用时用科目余额填右列。
5. **右列先信核算项目余额表（部门）**。总部有引出就用引出，不要用凭证辅助凑。Downloads 里的 `核算项目余额表*.xlsx` 也能认。工资/社保/公积金：有职工薪酬台账就按组织架构拆到叶子（渠道开发中心进研发 5503；本地化销售第 1 列、成本第 2 列；四川进财务中心，不进四川分公司列）。没台账且核算项目也没挂部门 → 右列空着，运行报告 `ask=` 原样问她，禁止倒填损益表、禁止按人数猜。 湖南分/子（`config/薪酬台账.json` `left_resplit_entities`）：金蝶 5602 工资/社保/公积金整笔，台账同项合计与金蝶相等（容差 0.01）才清金蝶那格、按台账拆到 5401/5502/5501 左右两列（报告 `薪酬左列重分=`）；不等就不动金蝶、报告 `薪酬左列未重分=`，禁止硬凑。文化和上海的本公司工资在有台账后改走台账，差旅/房租仍走本公司规则。文化和上海 5101 本公司不进视听/本地化，残差进营销总监及助理；总部收入里挂「济南分公司」的改挂渠道开发中心。投资收益叶子无部门的进总经办。损益发生额与核对同口径（收入看贷方、费用看借方）；总部有科目余额引出时左列用引出，不用凭证结转双边。斯佳指定整笔归集（`config/残差归集.json`，覆盖核算项目拆分）：折旧费/无形资产摊销→运营保障中心；税金及附加树（5402）和财务费用树（5504）→财务中心；540103 翻译语言服务→项目总监及助理。
6. 湖南分抄进金蝶之后必须**重新引出**科目余额/核算项目/利润表。入账前的空引出当没源。总部房租摘要含「深圳」进广东分公司、「长沙」进湖南分公司；没有摘要源则留运保，禁止残差一律进广东。
7. **先清洗再填数。** 表头别名在 `config/引出列名.json`（科目代码、本期发生额（借方）、2026.07、2026年7期都认）。期间只认表头、文件名、工作表名里的会计期间。金额格子（如 `2062.07`）不参与，不能把整张表判成跨月。同一文件里只有一个期间时，没写期间的 sheet 跟随它。没写期间、期间不是本次月份、表头认不出：这些文件的数不进本期，运行报告写 `清洗未用=`，`ask=` 原样问斯佳要当期引出。禁止拿别的月份成品、旧桌面夹、本年累计凑本期。上月只收利润表，而且必须是本次期间的上一个月。
8. 真实引出不进 git。不要对系统 Python `pip install`。不要读「内网勿外传」口令 md，不要复用 Chrome 配置目录。

## 0.6 总流程（先源 Excel，再核算）

Agent 按这个顺序做，不要半套源就出损益表：

1. **总部 API → Excel**：`scripts/dump_api_excel.py --period YYYYMM --out-dir <材料夹>/API`。YYYYMM 用她说的月份，没说就用上一个已过完的公历月。科目余额 OpenAPI 400 时脚本用凭证汇总，一样落成表。只报文件名和占用个数。
2. **网页 Playwright → Excel**：文化/上海/湖南分/湖南子的科目余额、核算项目、利润表查询页（`gl_profitsheet1`，本月金额）。总部网页科目/核算缺了，点名 `jiagu` 再拉；有网页文件就优先，API 那份只对照、不叠两遍。
3. **斯佳给的源**（录音 + 技能家口径）：山东/四川/济南只有**代账小企业利润表**（会小企 / 本月金额），不是金蝶科目余额，也不是做好的损益表。放进同一材料夹。她交的 `损益类部门科目余额表` 是**答案金标**，只对照，不当源。文件名带假数/明昊测试的薪酬台账不喂。
4. **核算**：材料夹已齐后再跑下面的 `convert.py`。右列、本公司、残差、房租摘要、济南减法都走本地 `config/`，禁止改数凑平。

`convert.py` 自己也会先把总部 API 落到 `01_脏数据/API/`，再补网页缺口，洗进 `02_清洗后/模型_YYYYMM.xlsx`，再只按这本模型拼 `03_结果`。同事说「月度损益表」时仍只跑这一条。

## 0.8 三层文件夹（人看模型，结果不读脏表）

| 文件夹 | 放什么 | 谁写 |
|--------|--------|------|
| `01_脏数据/` | 金蝶引出、API 落表、斯佳交的代账和薪酬原件 | 脚本收进来。人只看，不在这里改数 |

## 1. 就跑这一条

她没给文件夹时**原样**跑。`--period` 用她说的月份；没说就用上一个已过完的公历月。不要写死 202608。


## 2. 收尾（照抄）

> 月度损益表已出，期间 YYYYMM。材料夹：…。有源账套：…；缺源：…。利润表缺源：…。利润表上月缺线下：…。未映射部门 N 个。核对非 0 的科目编码 M 个。表在 \<路径\>，运行报告在同目录。请打开看两个 sheet，不要改数凑平。

只报编码：绿行 / 父行 / 未映射 / 其它。其它必须无。未映射是对不上的部门，不要猜进某一列。不要问「要不要改数」。有 `ask=` 或利润表缺源不是无时先问 `ask=`。利润表上月缺线下不是无：告诉她这三列先空着，有上月代账再补，没有就先这样。`没取到`、`取到本期发生为0`、`清洗未用`、`网页期间未对准` 不是「无」时照抄，按 0.7 留空，不要补数。`产物=未生成` 时不要说表已出。`网页期间未对准` 不是登录失败。
