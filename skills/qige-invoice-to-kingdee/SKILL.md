# 琪哥发票入金蝶

把改样发票簿转成金蝶「凭证引入」xlsx。不点金蝶引入/审核/过账。

**核心原则：用它的是财务同事。她给发票簿，你认文件、跑脚本、交两份表。别让她改文件名、看列号、另做规则 Excel。**

金额、借贷、科目只由 `scripts/convert.py` 算。对话里只报笔数和路径，禁止报客户名、金额明细。

## 你（agent）该怎么干

### 0. 红线

1. 禁止自写 Python 读她的发票表；只准调本技能 `scripts/convert.py`。
2. 禁止猜客户映射、禁止用余额表猜科目。对不上 → 明细 hold。
3. 禁止点金蝶「开始引入 / 审核 / 过账」。
4. 真实 xlsx / 金蝶档案 json 不进 git。

### 1. 找输入（按内容认）

需要：① **改样发票簿**（同时有 sheet `发票` + `组织架构`）② **金蝶档案 json**（含 `employee` / `customer` / `department`）。金蝶空模技能自带，不必她每月再给。

```bash
python3 "<本skill目录>/scripts/convert.py" --inspect --input-dir <放文件的绝对目录>
```

认准了才跑。缺档案 json 就停，让她把金蝶引出的基础资料放进来（或指到本机已有那份）。

### 2. 跑转换

```bash
python3 "<本skill目录>/scripts/convert.py" \
  --invoice <发票簿绝对路径> \
  --master <金蝶档案json绝对路径> \
  --out <交付目录绝对路径>
```

可加 `--date YYYY-MM-DD`（默认当天）。`--invoice/--master` 可省，改从 `--input-dir` 认。

产出：`发票入金蝶_明细_*.xlsx`（每张都在）+ `凭证引入_发票_*.xlsx`（只写可入账）。

### 3. 规则在哪

`config/业务规则.md` + `config/rules.json`。列名变了改 `config/列名别名.json`。空模在 `config/凭证引入空模.xlsx`。

### 4. 收尾（人话）

- *「这批 N 张：可入账 X，待确认 Y。两份表在 \<路径\>。请您看明细里待确认，再自己去金蝶引入。我没有点引入。」*
- 待确认只报**原因类别和笔数**（缺科目 / 客户对不上 / 职员对不上），不报名称金额。
- 空行已跳过，不算进 N。

## 硬禁止

- 不要把第三份「规则维护 Excel」当成输入。
- 不要用发票表「日期」当记账日期。
- 不要信发票 I 列部门缓存，脚本读组织架构 sheet。
- 环境缺库转 **env-doctor**（openpyxl）。
