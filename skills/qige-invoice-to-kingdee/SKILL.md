把改样发票簿填进金蝶「凭证引入」xlsx。不点金蝶引入/审核/过账。

**核心原则：用它的是财务同事。她给发票簿，你认文件、跑脚本、把填好的表放回同一文件夹。别让她改文件名、另交空模或档案 json。**

金额、借贷、科目只由 `scripts/convert.py` 算。对话里只报笔数和路径，禁止报客户名、金额明细。

## 你（agent）该怎么干

### 0. 红线

1. 禁止自写 Python 读她的发票表；只准调本技能 `scripts/convert.py`。
2. 禁止猜客户映射、禁止用余额表猜科目。缺科目 → 明细 hold，不进金蝶表。
3. 禁止点金蝶「开始引入 / 审核 / 过账」。
4. 真实 xlsx 不进 git。不要向她另要金蝶空模或档案 json。

### 1. 找输入（按内容认）

只要 **改样发票簿**（同时有 sheet `发票` + `组织架构`）。金蝶空模在 `config/凭证引入空模.xlsx`，技能自带。

```bash
python3 "<本skill目录>/scripts/convert.py" --inspect --input-dir <放文件的绝对目录>
```

认准了才跑。缺发票簿才停。

### 2. 跑转换

```bash
python3 "<本skill目录>/scripts/convert.py" --input-dir <放发票簿的绝对目录>
```

可加 `--date YYYY-MM-DD`（默认当天）。产出写回**同一文件夹**，原件不动：

- `凭证引入_结果.xlsx` ← 按技能空模填好的金蝶引入表（只写可入账）
- `{发票簿文件名}_明细结果.xlsx` ← 每张都在，待确认写原因

已有「结果」字样的文件不会被当成输入。

### 3. 规则在哪

`config/业务规则.md` + `config/rules.json`。列名变了改 `config/列名别名.json`。金蝶换官方模板时替换 `config/凭证引入空模.xlsx`。

### 4. 收尾（人话）

- *「这批 N 张：可入账 X，待确认 Y。填好的金蝶表在 \<路径\>。请您看待确认，再自己去金蝶引入。我没有点引入。」*
- 待确认只报**原因类别和笔数**（缺科目 / 组织架构对不上 / 档案一对多），不报名称金额。
- 空行已跳过，不算进 N。
- 客户/职员编码能从可选档案 json 精确对上就填；对不上就填名称、编码留空，**不许猜**。

- 不要用发票表「日期」当记账日期。
- 不要信发票 I 列部门缓存，脚本读组织架构 sheet。
