# 琪哥发票入金蝶 · 业务规则

数值以同夹 `rules.json` 为准。改口径改 json + 本文，不改 Python。

## 范围

只做发票。每月输入 = 改样发票簿（`发票` + `组织架构`）。金蝶空模技能自带。不做流水 / 收款 / 付款。不另要档案 json。

## 入账

| 项 | 口径 |
|----|------|
| 记账日期 | 跑技能当天（不取发票表「日期」） |
| 凭证字 | `记` |
| 打包 | 按表顺序，仅可入账行，大约每 **5** 张一记。若按 5 切开后，下一记第一家与上一记最后一家是同一公司，并进上一记，不硬切；连续同公司可以超过 5。末包可不足 5。非连续的同一公司不合并 |
| 销项税 | `21710105`，不挂辅助 |
| 币别 / 汇率 | `RMB` / `1` |
| 金额 | 用表列价税合计 / 金额 / 税额；公式未算出时按表公式 `ROUND(价税合计/1.06,2)` 与 `税额=价税合计-金额` 取值，不另编税率 |
| 科目 | 照抄表里应收、收入编码。名称用金蝶科目全称（下划线，如 `应交税费_应交增值税_销项税额`）。引入以编码为准，名称列给人看；编码和名称不要塞进同一格 |
| 部门 | 读本簿 `组织架构`（姓名→部门编码），不信发票 I 列缓存 |
| 职员 / 客户 | 名称填单位名称 / 申请人；若旁边有档案 json 且精确匹配到唯一编码则填编码。对不上留空码，禁止猜映射 |
| 摘要 | `{发票类型}：{单位名称}`；金额为负且类型未写「红字」时前加「红字」 |
| 分录 | 借应收（价税合计）/ 贷收入（金额）/ 贷销项税（税额） |

## 名称怎么比

去首尾空格，半角括号改全角。**不**删「有限公司」等后缀。档案零命中 → 仍入账、编码留空；一对多 → hold。禁止猜映射。

## hold（不进金蝶表，明细必须留行）

- 缺应收或收入科目编码
- 缺金额，或价税合计不等于金额加税额
- 缺发票类型 / 缺申请人
- 组织架构没有此人 / 重名 / 部门编码空
- 可选档案 json 里客户或职员一对多

空行（单位名称为空）跳过，不算源行。

## 产出

写回她放发票簿的同一文件夹，原件不动：`凭证引入_结果.xlsx`、`{发票簿文件名}_明细结果.xlsx`。

## 禁止

- 用余额表「金额大」猜科目
- 猜客户映射（县公安→公安部等）
- 点金蝶引入 / 审核 / 过账
- 把客户名、金额明细打进对话
