# 琪哥发票入金蝶 · 业务规则

数值以同夹 `rules.json` 为准。改口径改 json + 本文，不改 Python。

## 范围

只做发票。源 = 改样发票簿（`发票` + `组织架构`）。不做流水 / 收款 / 付款。

## 入账

| 项 | 口径 |
|----|------|
| 记账日期 | 跑技能当天（不取发票表「日期」） |
| 凭证字 | `记` |
| 打包 | 按表顺序，仅可入账行，每 **5** 张一记；末包可不足 5 |
| 销项税 | `21710105`，不挂辅助 |
| 币别 / 汇率 | `RMB` / `1` |
| 金额 | 用表列价税合计 / 金额 / 税额；公式未算出时按表公式 `ROUND(价税合计/1.06,2)` 与 `税额=价税合计-金额` 取值，不另编税率 |
| 科目 | 照抄表里应收、收入编码 |
| 部门 | 读本簿 `组织架构`（姓名→部门编码），不信发票 I 列缓存 |
| 职员 / 客户 | 名称规范化后精确匹配金蝶档案；编码自己取 |
| 摘要 | `{发票类型}：{单位名称}`；金额为负且类型未写「红字」时前加「红字」 |
| 分录 | 借应收（价税合计）/ 贷收入（金额）/ 贷销项税（税额） |

## 名称怎么比

去首尾空格，半角括号改全角。**不**删「有限公司」等后缀。对不上或一对多 → hold。

## hold（不进金蝶表，明细必须留行）

- 缺应收或收入科目编码
- 缺申请人，或组织架构没有此人 / 部门编码空
- 客户档案零命中或一对多
- 职员档案零命中或一对多
- 部门编码在金蝶部门档案里没有

空行（单位名称为空）跳过，不算源行。

## 禁止

- 用余额表「金额大」猜科目
- 猜客户映射（县公安→公安部等）
- 点金蝶引入 / 审核 / 过账
- 把客户名、金额明细打进对话
