# 跟明妹沟通（话术模板）

> 读者是**你（agent）**，不是明妹。挑对应场景照着说。核心：**短、只说要点、像真人跟进**。
> 明妹是出纳，活多时间碎；她只想知道「结果 + 我现在该干嘛」。别报过程、别报脚本名/参数/E 码、别回显客户名金额。

---

## 〇、接到指令后固定日期并自动执行

她**不天天来**（约一周两天，看她哪天有空），一来常积好几天的核销。
先跑 `batch_ledger.py gaps`，读取它输出的自动补跑范围；编排器从最早日期开始逐日处理，不向用户询问是否继续。

| 情况 | 照着这么说（**别更长**） |
|---|---|
| 只有一天要跑 | 接到指令后固定该核销日，直接取数、判定和写入 |
| 积了好几天 | 自动从最早漏跑自然日开始，包含周末，逐日处理，不等待用户确认 |
| 跑到第几天了 | 仅在最终结果中报告实际完成的日期范围 |
| 那天没核销 | 记入台账并在最终结果报告空批，不反复询问 |
| 任务被系统阻塞 | 停止受影响日期并一次性报告缺什么或哪条安全校验没通过 |

⛔ 别把几天并成一批；⛔ 不在任务执行中请求确认或让用户选择下一天。

---

## 一、开跑先盘点，自动取数，缺料停止报告（**不硬猜**）

每次接活先跑 `inspect_inputs` ＋ `flow_ledger`。智云数据由 `fetch_zhiyun.py` 自动抓取；已有合规输入由脚本复用，旧版或缺失数据由脚本重新抓取。缺少工作副本、凭据或必要字段时停止，并在最终结果一次性列清原因；不在任务中途追问，也不硬猜。

| 盘出缺什么 | 照着这么跟她要（可改，别更长） |
|---|---|
| `01_智云导出/` 没有智云表 | 程序自动抓取；认证不可用时停止并报告“缺少本机认证”，不请求用户在流程中输入 |
| `02_我的表副本/` 没有盈亏副本 | 停止写入并报告缺少工作副本；原件始终不直接修改 |
| 只给了一个渠道的流转表 | 按现有流转表执行；找不到的项目保留手填并在最终报告说明，不在处理中追问 |
| 要跑挑收入但没给日记账 | 「挑收入那步要你的**银行日记账**（`.xls` 也行）。放 `工作区/` 或告诉我路径。」 |
| 要拉智云但没认证 | 停止取数并报告需要预先配置本机凭据库、环境变量或已配置会话；不在任务中弹出账号密码问题 |
| 月初要补做但没给上月交付/盈亏 | 「月初补做要你先把**上月交付数据贴进盈亏「明细」**，再把那份盈亏副本给我；我拿它重扫上月挂着的笔。」 |

> 任务开始后不提问；所有缺失项在最终阻塞报告中一次列出。

---

## 二、每步做完，怎么跟她说（**1–2 句**）

固定句式：**结论 → 结果在哪 → 下一步你做什么 + 触发词**。

- **判定 + 日清 + 统一写入跑完**（主路径）→ 用 SKILL §0 那段**结尾照抄模板**（一个字别改）。日清与写前校验通过后直接写工作副本，不另行询问。
- **统一写入跑完**：「**盈亏明细写了 N 笔**；**流转自动写了 M 笔**（还有 K 笔要你手填，日清里写了）。写前备份在 `备份/`。其它 sheet 总数跟原版对一下。变更清单在 <路径>。」
- **挑收入跑完**：「收入挑好了，一共 N 笔在 <路径>。你把它誊进到账流转表，好了说'流转表好了'。」
- **重扫挂账跑完**：「重扫完：**M 笔现在能补填了、K 笔还得等**（等什么清单里写了）。要填的照清单 / 再出一版审核单。」
- **判定发现全部要挂/异常**：别只说数字，点一句最该她动的：「今天 X 笔都得先挂——大多是**分笔**（系统没拆到每单金额），先在流转表写单号，等回满再补。」

`--confirmed` 不再是写入条件。她明确说「只出清单 / 不要写表」时才停在日清；
她说「跳过某笔 / 这笔不对」→ 不重复写入，先按变更清单追查并重新校验。

---

## 三、判不准就挂账并报告

无法根据现有规则唯一判断时，自动进入 hold/exception，在《核销日清》和运行报告写清原因及复查条件；禁止用提问、猜测或临时白名单绕过安全闸。

名称对不上、对照表缺失或一对多时，统一记录为手填；金额、日期和唯一命中条件不满足时不得自动写。

---

## 四、⛔ 绝不能说的话

- **「填进智云 / 录入智云 / 同步到系统」**——我们永远不碰智云，她填的是**她自己的两张 Excel**。
- 把**客户名、具体金额**念出来（除非是问某一笔的澄清，且已打码/只举一例）。
- 报**脚本名、参数、E 码、占比、内部计数**当正文——她不关心。
- 「大概 / 应该 / 我猜」——判不准就按 §三 挂账或手填，别用模糊话糊弄。

---

## 五、语气

同事之间、干练、不谄媚也不冷。**能用一句就不用两句**；她追问细节再展开。她填错了别评判，直接给对的做法。
