# 应收核销日清 · 使用说明（给明妹）

> 读者是出纳，不是程序员。照着做就行。
> **2026-07-23 改版**：产出从两个文件九个页签，合并成**一份《核销日清》**；
> 第一列是单号，第二列是状态，问题类型直接变成一列。

---

## 1. 一次性准备

1. 电脑上已有本技能文件夹（同事会帮你放好）。
2. 需要 Python 和 `openpyxl`（同事装好；你一般不用管）。
3. 记住工作区长这样：

```
工作区/
  01_智云导出/     ← 程序自动从智云抓取的表
  02_我的表副本/   ← 盈亏表、流转表「另存为」副本放这里（原件别直接丢进来）
  03_台账/         ← 电脑自动维护：挂账台账 + 跑批台账（哪天跑过、哪天漏了）
  04_产出/         ← 单日任务按核销日拿《核销日清》；多日任务只拿本次日期范围版，每类一份
```

> 想知道有没有漏跑的天，随时问一句「**哪几天没跑**」。

4. 第一次可先让同事帮你跑一遍「盘点」，看文件夹是否认得出。

---

## 2. 每天怎么做（主战场从「筛核销」开始）

> 前面日记账 / 挑收入 / 建回款你照旧自己做；**自动化重点从智云筛核销开始**。
> 销售何时核销不用管——筛的是**核销日期**，核了就进那天，没核就进更后的日子。

0. **说出核销指令即可**（2026-08-17 起）
   - 你说「跑昨天的核销」或指定某一天，程序会在入口固定核销日期，不再让你重复确认。
   - 前面记日记账、挑收入、建回款走的是**钱哪天到的账**；这里筛的是**销售哪天在智云核销**，两个日期可能不同。
   - 程序会先查漏跑日期；有漏跑时从最早自然日开始逐日处理，周末也会检查，不把多天合成一批，也不在中途等你选择下一天。
     > 为什么不一次性几天一起？因为同一个订单可能**分两天核销**，两次填的是你表里同一行——
     > 先早后晚一天一天来才接得上。你不用管这个，它自己会排。
   - 那天要是一笔核销都没有，它会明说「这天没有核销」——**那是正常的，不是出错**。

1. **智云数据（真相源）**
   - 发出核销指令后，程序自动去财务管理→回款记录，**只按任务固定的核销日期**筛选，
     再抓每笔到账的明细页。认证只使用本机凭据库、环境变量或已配置会话，不在取数过程中询问账号密码。

2. **盈亏工作副本**
   固定用一份**副本**（原件自己留着对照）。程序**只改「明细」这一个 sheet**，其它 sheet 不动。
   你怎么验：看副本**其它 sheet 底下总数**是否还和原版一致。

3. **流转表副本**
   放进 `02_我的表副本/`，用来对到账、写单号。
   程序在智云取数后先把 `SO  交付金额` 写进「单号」格，一单一行；盈亏核销完成后再更新「是否更新应收款」。**空 和 「部分」都要再做**；“部分”时红字仍表示未核销的 SO。PayPal/美元户付款方为英文时，程序按「到账名称→系统客户名称」对照表转换后再与智云客户名称匹配；对照缺失或一对多的行转人工。

4. **说核销指令后**
   它会取数 → 判定 → 校验 → 出**一份《核销日清》**（盈亏要填几行 + 流转自动写几笔/手填几笔），
   随后先备份并直接写工作副本，再逐格回读。只有你明确说“只出清单/不要写表”才停在日清。

5. **查看《核销日清》和写后差异**
   - 《先看这里》：盈亏 N/S/C + 流转自动写 M / 须手填 F  
   - 《今日清单》：筛「今天要填」  
   - 《流转表怎么填》：写入方式=**自动** 的程序已经写；=**手填** 的你自己填  
   - 《订单写入差异》：核对本批计划值与写后实际值是否一致  
   有问题就说「这笔不对」，程序按变更清单和写后回读追查，不重复写入。

   > ⏰ 程序运行期间不要同时打开并修改工作副本（尤其别插行）。  
   > 写入前会再核一遍；发现表在校验后变化就**一个字都不写**，重新校验并重出日清。

6. **挂账**
   挂着的处理完了，说「重扫挂账」。

## 3. 《核销日清》怎么看

**只有这一份，别的表都不用开。**

### 页签「先看这里」

一屏看完：今天要填几行、跳过几行、冲突几行、挂账几行、异常几行，和怎么用。
若智云疑似生成重复核销记录，还会显示纠正了几笔父回款、几个重复组、忽略了几条记录。

### 页签「今日清单」（主表）

**一行 = 一个单号（SOD）。第一列单号，第二列状态。**

| 状态 | 意思 | 你要干嘛 |
|---|---|---|
| **今天要填** | 电脑算好了，你表里那行还是空的 | 照「应填_xxx」填进去 |
| **已填过·跳过** | 你之前填过，而且跟这次算的一样 | **不用管**（这就是你问的"我明明填过了"那类） |
| **冲突·需你定** | 你填过，但跟这次算的不一样 | 看「当前值与计划值的比较差异」那列，你定按哪个来 |
| **挂账待办** | 今天填不了 | 看「怎么办」那列 |
| **异常** | 数据不对劲 | 先别填，按「怎么办」查清楚 |

其它列：

| 列 | 意思 |
|---|---|
| 怎么办 | 这一行该干嘛，一句话 |
| SO / 到账号(AR) / 客户(打码) | 定位信息，客户名只显示打码 |
| 怎么找到这行 | **按 SO 号在盈亏表筛选**，不要按行号（表会插行，行号会变） |
| 应填_计提 / 回款明细 / 业务值差异 / 是否结账 / 收款时间 / 收款方式 / 实收SOD | 建议填什么；业务值差异是盈亏表真实字段 |
| 当前_* | 你表里现在是什么，包括当前业务值差异 |
| 当前值与计划值的比较差异 | 审核说明：哪一列、表里是啥、这次算的是啥；不写进业务表 |
| 判定依据 / 码 | 一句话为什么这样判 |

### 页签「流转表怎么填」

到账流转表「是否更新应收款」建议：

| 建议 | 你怎么填 |
|------|----------|
| （空白） | 关联的单**都还没交付进表** → **留空**，不要写公式 |
| 是 | 这些单这次都能更（**包括钱没到齐、你要拆行的那种**）→ 填「是」（有惯用公式可套公式） |
| 部分 | 只有部分 SO 完成盈亏核销 → 填「部分」，**未核销的 SO 标红，已核销的保持正常色** |

> 说明：只有"订单还没交付进表、你没法更新"才算「部分」。像"部分回款、你把它拆成已收/未收两行"
> 这种，钱已经全核掉了、你也更新了 → 算「是」，不再误标「部分」。

## 4. 挂账 / 异常怎么办

（大白话，不记代号）

| 你看到的话 | 你该做什么 | 找谁 |
|---|---|---|
| 分笔回款，系统没有拆到每张单的金额 | 先挂着；流转表可只写单号；等回满或销售补清再补盈亏 | 销售 |
| 盈亏表里还没有这张单 | 等月初贴完交付，再说「重扫挂账」 | 自己 / 月初流程 |
| 跨年的单 | 程序按智云订单详情里的项目交付日期查对应年度盈亏工作副本；日期缺失或冲突、缺那年的表或表里缺单才挂账 | 自己 / 主管 |
| 核销金额比到账还多 | 先别填，查系统是不是录错 | 销售 |
| 智云同一父回款下出现可完全解释超核销的精确重复记录 | 清单会明确写“每组只按一次处理”并给出折叠前后差额 | 程序自动纠正并警告 |
| 超核销无法由精确重复完全解释，或核销记录没有记录号/币种不可比 | 整笔先挂着，不会只挑部分订单写；人工检查智云核销记录 | 自己 / 销售 |
| **这单没回满** | 看清单里的原始应收、最新交付、累计回款、实际未收。普通情况拆行后应收合计不变；如果最新交付额大于原始应收，原行保留原始应收，新增未结清行应收留空，实际未收只用于后续判断。累计未回满时计提都空，最后回满才填最新交付额 | 程序自动 |
| **同一个 SO 有多个 SOD** | 单个 SOD 核销完成时先不填计提；同 SO 的全部 SOD 都核销完成后，再按各 SOD 最新交付额补填。一个 SOD 有多条回款行时，只在最后一条已结清行填一次 | 程序自动 |
| **本次核完最后几个 SOD，触发以前月份的计提补填** | 《核销日清》会增加“跨月计提补填”页，列出这个 SO、本次 SOD、以前 SOD、历史月份、补填金额和写前校验结果。月份优先看以前的日清；以前日清没有时看盈亏表收款时间；两个日期都没有才写“待确认” | 程序自动提示并补填 |
| **分不清这次核的是哪几个明细单** | 清单上列了候选 SOD 和金额，你指一下 | 自己 |
| 智云已有本次核销金额但没有汇率 | 直接按本次核销金额处理，不再补汇率 | 程序自动 |
| 没有单号或已作废 | 跳过；无单号问销售 | 销售 |
| 这张单在表里有好几行一样的金额 | 你指定记哪一行再填 | 自己 |
| 带手续费 | 忽略手续费字段，按逐 SO 本次核销金额处理 | 程序自动 |
| 这笔到账在系统里没挂订单 | 去智云看这笔回款建对了没 | 自己 / 销售 |

## 5. 哪些它不会做

- **不替你录智云**（永不自动往系统写数据）。
- **不碰你盈亏表的原版、也不碰「明细」以外的任何 sheet**（原版你留着比总数验收）。
  回填只往你固定用的那份**工作副本的「明细」**里写，写前先自动备份一份。
- 不跳过《核销日清》和写前校验；通过后直接写工作副本，无需另行说“确认”。
- 到账流转表先按到账日期和到账金额找候选行，再拿智云销售名称或客户名称去匹配公司名称或汇款人；名称匹配后只有一行时，才自动写单号和是否更新，对不上的仍手填。
- **分笔回款**判不了金额，只能挂起。
- **要拆行的**（钱没到齐那种）只提示，不替你插行。
- 不替销售做核销。

## 6. 出错了怎么办

1. 看弹窗或对话里的「ERROR」全文。
2. 若提示「表头缺列…实际表头：…」——说明导出的列名和预设对不上，把报错截图给同事，别自己猜列。
3. 日志/报告在 `04_产出/运行报告_*.txt`。
4. 找谁：先找部署技能的同事（明昊侧）；业务口径找你自己或主管。

## 7. 常见问题

**Q：导出的表头和以前不一样？**
A：程序按中文列名模糊认。认不出就报错停下，不会瞎猜。把实际表头发给同事加别名即可。

**Q：跑一半停了？**
A：看报错。改完文件后从断的那步重跑；判定和清单可重复跑。

**Q：同一天跑两遍会不会重复？**
A：不会。第二遍会认出「已填过·跳过」，不会再让你填一遍，也不会重复写。

**Q：为什么同时有工作副本和“便携版”？**
A：工作副本保留原表的历史外链，继续留在固定电脑上做后续核销。便携版已把历史外链当前显示值固定下来，换电脑打开更快，也不会再去找原电脑上的外部文件。便携版只用于发送和查看，下一次核销仍使用工作副本。

**Q：怎么知道它算得对不对？**
A：拿你 7 月 22 号那天的真实数据完整回放过一遍——13 笔到账拆成 157 行，
其中 **143 行程序算的和你当天手工填的逐格一模一样**，一处都没差；
剩下 14 行是真填不了的（3 张单还没交付、8 张 2025 年老单、2 处要你先拆行、1 张 7 月新单没交付）。

**Q：预存类准不准？**
A：7-22 那天三笔预存回款（含一笔部分核销）都在上面那次回放里，算对了。
仍可随时用日清、变更清单和订单写入差异做并排复核。

**Q：收入提取那步？**
A：把银行日记账给程序，它会挑出纯销售收入清单；空预填行会自动跳过；美元和人民币不会混加。
