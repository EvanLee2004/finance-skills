## 一、先校验父 AR 核销记录

```text
同一核销记录NUM跨快照 ──────→ 只保留最新物理记录；不是系统重复
撤销记录 ───────────────────→ 保留审计，完全排除金额
delta_raw >= -1.00 ─────────→ normal/tolerance；不同记录号全部保留
delta_raw < -1.00：
  精确重复折叠后 >= -1.00 ──→ recovered；每组只保留一次，警告 W_SYSTEM_DUPLICATE_WRITEOFF_COLLAPSED
  其余情况 ─────────────────→ 父 AR 全部 hold/exception E_SYSTEM_OVER_WRITEOFF_UNRESOLVED
```

精确重复仅限同一父 AR 的相同 SO、相同金额、相同币种口径且不同核销记录NUM；原币和本币
同时存在时二者都要一致。系统重复忽略行同时退出本次 `H` 与累计 `R`。缺记录号或口径不可比时不得猜。

## 二、按「每笔到账」再定性

```
分笔回款 ────────────────────→ hold E1（系统无逐单金额，禁止比例分摊）
手续费 > 0 ─────────────────→ 忽略手续费字段，继续读取逐 SO 本次核销金额
有本次核销金额本币 ─────────→ 直接使用本币金额
仅有本次核销金额 ───────────→ 直接作为业务金额，不要求父回款汇率
逐 SO 核销明细为 0 行 ──────→ 按最新实际交付额全额核销
下单栏为空 ──────────────────→ exception E7（这笔回款在智云没挂订单）
否则 ────────────────────────→ 进第二步逐 SO 展开
```

**硬校验**：每笔到账至少产出 1 条判定；`expand_payments` 出口比对
`{到账的 AR}` 与 `{判定的 AR}`，不等就 `CoverageError` 报错退出。

## 三、逐 SO → SOD

```
H[so] = 核销明细的本次核销额（该表本次 0 行 → 该 SO 交付额）
lines = 订单明细[SO]

H[so] == Σlines ──────────→ 全部 SOD 入选
凑得出唯一子集 ───────────→ 只填这几个 SOD
多解 / 无解 / SOD > 22 行 ─→ hold E5，把候选 SOD 与金额摆出来给她挑
lines 为空 ───────────────→ 退化：按 SO 匹配盈亏表（仍可判）
```

## 四、每个 SOD → 盈亏表定位

```
① SO + 应收金额  → 唯一行 ✅（主键：回填前后都成立）
② SOD            → 唯一行 ✅（她回填过「实收金额」列时；幂等重跑走这条）
③ SO             → 唯一行 ✅
④ 多行同额       → 整段逐位对齐（SOD 降序 ↔ 行号升序，金额序列全等）✅
                   对不齐 → hold E8，候选行号仅供参考
⑤ 表里没有       → SO 是往年 → hold E3；否则 hold E2
⑥ 本次两条命中同一行 → 两条都 hold E8（谁对谁错要人定）
本行应收 < 本次金额 → exception E4
流转三键 0 命中 / 多命中 → E0 / E12（仅在 --flow-complete 时判 E0）
```
