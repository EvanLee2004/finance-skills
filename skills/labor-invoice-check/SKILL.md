# 劳务发票核对（月初做账）

把已经发出去的劳务费，按人拆成「有票 / 800以下不提供发票 / 无票」。  
**钱已经付了。** 不是付款前催票，也不许改应发。你是来做账的同事，不是一台只会按文件名跑的机器。

路径一律绝对路径。脚本在「这份 SKILL.md 所在文件夹」。  
**只准跑** `scripts/monthly_close.py`。看到 `check.py`、`可付`、`催票`、`_old_labor-invoice` 就是旧付款前，立刻停，改跑 `monthly_close.py`。

## 她说什么就做什么

| 她说 | 你做 |
|------|------|
| 做这个月劳务发票统计 / 劳务发票核对 / 做账 / 对完成版 | 认文件夹 → 调 `scripts/monthly_close.py` |
| 没说月份 | **上一个已过完的公历月**（9 月说「这个月」= 8 月 = `202608`）。脚本自己也会这么猜 |
| 文件夹里还有完成版、上个月发票 | 正常。完成版只能 `--gold` 对人数；发票用当月那张。**不要靠排序拿第一张** |
| 当月汇总对不上 / 她提到服务器或译员对账清单 | **不要去共享盘、不要 SSH、不要 `--invoice-dir`。** 进待人工，把 `ask=` 原样问她人核 |
| 应收合并 / 金蝶 / 催谁付款 | **不是本技能** |

## 1. 先认文件，再算

文件夹经常同时有：应发明细、**7 月和 8 月两张发票**、她的完成版。发票汇总里还夹着她自己的做账底稿 sheet。  
**按内容认，不靠文件名，也不要自己打开格子加总。**

```bash
python3 "<本skill目录>/scripts/monthly_close.py" --inspect --input-dir <文件夹绝对路径>
```

看 stdout：`pay_file` 必须是应发明细（姓名+应发，**没有**有票/无票三列）；`invoice_file` 必须是当月发票（Sheet1 有销售方+合计金额）；`gold_file` 若有，只拿来对人数。  
`month` 不对就加 `--month YYYYMM` 再 inspect。对了再做账。

## 2. 做账（优先让脚本认文件夹）

她把表放在一个夹里时，**不要自己点名文件**——点错就会拿完成版当应发、拿上个月发票：

```bash
python3 "<本skill目录>/scripts/monthly_close.py" \
  --input-dir <文件夹绝对路径> \
  --out <同一文件夹>/劳务发票统计_<月份>.xlsx
```

要写死路径时：`--pay` 应发明细，`--invoice` **当月**发票，`--month YYYYMM`，有完成版加 `--gold`。  
缺库：`python3 -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple openpyxl`

## 3. 你要理解的口径（数由脚本算）

- 有票 = 按**姓名**把当月 Sheet1 合计金额**加总**。一人多张必须加总；禁止 VLOOKUP 只取第一张。
- 空格、全角、大小写、`张三（个人）` 这种小格式，脚本会对齐。对不上的不要你改名硬配。
- ≤800 没票 → 800以下（外籍也一样）；≤800 有票 → 只进有票。
- 外籍 >800 没票 → 无票。国内 >800 当月没有 → **待人工**，三列先空。
- 少开：无票 = 应发 − 有票。多开不管。应发又大又整齐的一撮 → 单独写单，待人工。
- 金标人数对不上：差的人在「待人工」，等人核。**不是让你补数字，也不是去服务器取票。**

门槛在 `config/业务规则.md`。她口头改 800 / 容差 → 改 config 再重跑，不要改脚本。

## 4. 收尾（人话、只报笔数）

- *「8 月 N 人做完了：有票 X，800以下 Y，无票 Z，待人工 A+B。金标有票 G（若有）。结果在 &lt;路径&gt;。」*

## 本岗位该主动操心啥

1. 文件夹里是不是混进了完成版、上个月发票——inspect 对一下再算。
2. `ask_special` 那几人是单独写单，不是漏配。
3. 有票人数比金标少一截：请她看「待人工」，不要按完成版倒填，不要去共享盘。

## 硬禁止

1. 只准调「本 SKILL.md 所在夹」的 `scripts/monthly_close.py`。禁止 `check.py`，禁止 `python -c` / 自写 openpyxl 读表加总。

3. 拿不准 → `ask=`，禁止静默当有票。
