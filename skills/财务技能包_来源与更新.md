- macOS/Linux：`~/.config/opencode/skills/`
- Windows：`%USERPROFILE%\.config\opencode\skills\`

## 怎么更新（主路径：一句话）

对 opencode 说：

```
更新财务skills
```

（同义：「更新财务技能」「更新财务技能包」）

Agent 应：

1. 从 Gitee/GitHub **finance-skills** 的 **main** 拉最新（git pull 或浅 clone）  
2. 用仓内 `skills/*` **只覆盖下面白名单** 到本机 opencode skills  
3. **保留**你本地各技能里的 `config/`（销售归属、组织架构、config.local 等）  
4. **不动**白名单外你自己装的 / 自己做的 skill  
5. 汇报更新到的 **git short SHA**，提醒你 **重启 opencode**

完整可复制长提示词见仓库根目录 **`SOURCE.md` 第四节**；手册第三节 B 段同内容。
