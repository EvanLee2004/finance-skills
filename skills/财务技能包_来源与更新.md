# 财务技能包 · 来源

唯一源码仓：Gitee https://gitee.com/Lee157/finance-skills · 分支 `main` · 路径 `skills/<id>/`

开发：测绿 → `git push gitee main`。同事本机从 Gitee 拉 `main`，不要清空自己另装的技能。核销的 `config/` 跟仓库走，其它 skill 本机已有 `config/` 默认留着。

装在：macOS/Linux `~/.config/opencode/skills/`；Windows `%USERPROFILE%\.config\opencode\skills\`。

白名单见仓库根 `pack.json`。已下线：`env-doctor`、`qige-invoice-to-kingdee`、`task-clarifier`、`update-finance-skills`。缺库当场清华镜像装。

开口对照：同目录 `财务技能_说什么用哪个.md`。
