# 财务技能包 · 来源

**更新默认仓库：Gitee https://gitee.com/Lee157/finance-skills · 分支 `main`。** 不要去 GitHub。

同事说「更新财务部skills / 更新财务skills」→ 把这个 Gitee 的 `main` 拉到本机 opencode skills。路径 `skills/<id>/`。

仓库公开，不要登录，不要填用户名密码，不要改全局 git 配置。弹出 Git Credential Manager 就关掉。禁止普通 `git clone` / `git fetch` / `git pull`。每次 git 都加 `-c credential.helper=`：

```bash
git -c credential.helper= clone https://gitee.com/Lee157/finance-skills.git
git -c credential.helper= -C 仓库目录 fetch origin
git -c credential.helper= -C 仓库目录 pull --ff-only origin main
```

开发：测绿 → `git push gitee main`。不要清空自己另装的技能。核销的 `config/` 跟仓库走，其它 skill 本机已有 `config/` 默认留着。

装在：macOS/Linux `~/.config/opencode/skills/`；Windows `%USERPROFILE%\.config\opencode\skills\`。

白名单见仓库根 `pack.json`。已下线：`env-doctor`、`qige-invoice-to-kingdee`、`task-clarifier`、`update-finance-skills`、`compliance-spot-check`。缺库当场清华镜像装。

开口对照：同目录 `财务技能_说什么用哪个.md`。
