# 九点下单统计 · WorkBuddy 每日定时任务（可直接粘贴）

> **用途**：把这段配进 WorkBuddy 的定时任务，让它**每个工作日早上 9:00 自动跑**九点下单统计。
> **粘之前先确认三件事**（缺一跑不起来）：
> 1. 跑任务的那台机器**能上公司内网**（能打开 `http://192.168.10.167:18880`）
> 2. 那台机器上装好了 opencode + 财务技能包 + `playwright` 与 chromium
> 3. 技能目录下有 `config.local.json`（智云账号密码）——**密码只写在那个文件里，别写进任务提示词**

---

## 一、定时设置

| 项 | 值 | 为什么 |
|---|---|---|
| **触发时间** | **每天 09:00** | 「9 点快照」是锁死的口径。智云「下单日期」可被改期，晚跑数字会变小，跟旧 exe 对不上 |
| **重复** | 每天（含周末也可以跑，程序自己按规则算窗口） | 周末跑不会算错：周六抓周五、周日抓周五~周六 |
| **超时** | ≥ 10 分钟 | 登录 + 抓数 + 出表，正常 1~3 分钟；内网慢时留余量 |

> **法定节假日**：程序**不认节假日**，假期后第一个上班日只会抓"昨天"。
> 不用改定时——程序会**自己发现断档**并把漏掉的日期印在产物《统计区间》页上，照那页补一次即可。

---

## 二、任务提示词（整段复制进 WorkBuddy）

```
每天早上 9 点跑一次「九点下单统计」，用 order-daily-summary 这个技能。

要做的事：
1. 用技能里的 scripts/run.py 跑，输出到固定目录（下单统计产出文件夹）。
2. 跑完打开产物，看《统计区间》页，把下面几件事用大白话汇报给我：
   - 这次统计的是哪几天（逐日列出）
   - 总计多少万元、分部门各多少（多语（不含运保）/ 数据 / 游戏 / 其他）
   - 有没有「未匹配销售」，有的话把名字列出来
   - 《统计区间》页有没有红色的「⚠ 从来没统计过」的日期，有就原样念给我听
3. 文件放在哪，告诉我路径。

跑不起来的时候（任选其一发生）：
- 连不上内网 / 登录失败 / 抓数失败 → 别重试超过 2 次，直接告诉我「今天没跑成，原因是 XXX」
- 缺账号密码 → 提醒我去那台机器上补 config.local.json，别问我要密码、也别把密码打在对话里

红线：
- 绝不把智云账号密码写进对话、命令行或日志
- 只出数、不改智云、不发邮件
- 数字只由脚本算，你不要自己心算或估算
```

## 三、命令（如果 WorkBuddy 直接跑命令而不是喂 AI）

```bash
cd <财务技能包路径>/skills/order-daily-summary
python3 scripts/run.py --out "<固定产出目录>" --detail
```

**退出码**（WorkBuddy 可据此判成败）：

| 码 | 含义 | 该怎么办 |
|---|---|---|
| `0` | 成功 | 正常，看产物 |
| `2` | 缺凭据 / 缺组织架构表 | 去那台机器补 `config.local.json` 或组织架构 xlsx |
| `3` | **登录失败** | 查内网通不通、账号密码对不对 |
| `4` | **抓数失败** | 智云接口异常或网络中断，隔一会重跑 |

> ⚠ **非 0 一定要有人知道**。WorkBuddy 若不会在失败时通知，就在任务里加一句
> 「跑完把成败结果发我」——**静默失败比报错失败糟得多**：没人发现的话，
> 那天就是没数，而且事后看不出来。

## 四、每天该看什么（30 秒）

打开产物 xlsx，只看两页：

1. **《下单数据》** —— 行=日期、列=部门，数字在这
2. **《统计区间》** —— 这份表**统计的是哪几天**；底部如果有**红色**的
   「⚠ 有 N 个工作日从来没统计过」，说明有断档（多半是节假日或机器没跑），
   照那页的提示补一次

其余《处理日志》《明细》平时不用看，对数时再翻。

---

## 五、断档了怎么补（照做，别自己发挥）

从智云手工导出一张**覆盖那几天**的「下单」表，然后跑：

```bash
python3 scripts/run.py --out "<固定产出目录>" \
  --from-xlsx "<刚导出的那张表>" --no-date-filter
```

**⛔ 千万别用「一天一天补跑」**（`--today` 逐天）：
窗口是按**运行日倒推**的，周一那天的窗口是 3 天，逐天跑会**互相重叠**，
同一天被算好几遍 → 数字虚高。这条实测验证过。

## 六、口径备忘（免得又被当 bug 查）

- **「9 点快照」**：智云「下单日期」可被编辑，昨天的订单当天可能被改期、单号重排。
  所以同一天不同时刻跑，数字**本来就会不一样**——这是数据动了，**不是取数错**。
  晚于 09:15 跑，程序会在产物和输出里标红提示。
- **部门口径**来自 `config/销售组织架构.xlsx`，**不是**智云表里的「部门」字段。
  新销售入职要**先补进这张表**，否则他的单会落进「（未匹配）」。
- **日期窗口**：周一 → 上周五~周日；周二至周五 → 昨天；周六/日 → 上周五~昨天。
