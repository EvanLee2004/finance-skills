# 序时账入金蝶

把她每月发的 Excel 序时账抄进金蝶官方「凭证引入」模板。金额、借贷、凭证号只由 `scripts/convert.py` 写。人过目后自己去金蝶点引入。

湖南分公司抄作业走本技能，**不要**走 `kingdee-posting`（那是总部销项/付款/收款）。本技能不登智云、不读 `kingdee.local.json` / `zhiyun.local.json` / `xingchen.local.json`。缺库当场清华镜像装，失败再阿里 / 中科大 / 默认源。

## 启动时说

- **推荐**：序时账入金蝶
- 也可：抄作业入金蝶 / 湖南分入账 / 把这张序时账做成引入表 / 凭证导入模板

## 0. 她说什么就做什么

| 她说 | 做 |
|------|----|
| 序时账入金蝶 / 抄作业 / 湖南分入账 | **立刻**找表，调 `convert.py` |
| 凭证号从 11 开始 / 从记-11 开始 | 加 `--start-voucher-no 11` |
| 没说凭证号 | **不要**加起始号，沿用源表 |
| 给了文件夹或文件 | `--input` / `--input-dir` |
| 没给路径 | **不要**让她改文件名。脚本扫桌面和 Downloads |

## 1. 就跑这一条

```bash
python3 "<本skill目录>/scripts/convert.py" --input <她的xlsx>
```

她说了起始号：

```bash
python3 "<本skill目录>/scripts/convert.py" --input <她的xlsx> --start-voucher-no 11
```

没给 `--out-dir` 时默认写到桌面 `序时账入金蝶_YYYYMMDD/`。系统 python 缺库时脚本会切仓内 `.venv`。

## 2. 收尾（照抄运行报告第一段）

> 序时账已转成金蝶引入表：N 张 / M 行，凭证号 a～b，附件已清空。表在 \<路径\>。引入时请切到 \<账套全称\>。我没有点引入。

源表没写公司名称：提醒她确认账套（湖南分抄作业 = 湖南分公司，不要进总部 / 湖南子 / 文化 / 上海）。

## 3. 会变的在哪

| 文件 | 改什么 |
|------|--------|
| `config/列名别名.json` | 表头别名 |
| `config/凭证引入空模.xlsx` | 金蝶换官方模板时整份替换 |
| `config/业务规则.md` | 口径说明 |

对话只报张数、行数、凭证号区间、路径。禁止把分录金额打进对话。
