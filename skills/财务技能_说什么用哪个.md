## 亮晶

| 名称 | id | 简介 | 需要提供 |
|------|----|------|----------|
| 应收账款合并（亮晶） | receivables-merge | 分年表合成应收 all | Excel：本周源台账；最好再给上版应收 all |
| 应收按销售拆分（亮晶） | split-by-sales | 一人一份应收表 | Excel：一张应收 all |
| 合规文件抽查（亮晶） | compliance-spot-check | 建议抽查名单 | Excel：应收 all；可选抽查历史 |
| 劳务发票核对（亮晶） | labor-invoice-check | 有票 / 800 以下 / 无票 | Excel：应发明细 + 当月个人发票汇总 |
| 九点下单统计（亮晶） | order-daily-summary | 下单数据（万元） | 智云账号密码；或离线九点下单明细 Excel |
| 追觅应收进度对比（亮晶） | dreame-ar-progress-diff | 两版追觅进度差 | Excel：两版追觅应收 list |

开口：跑本周应收 / 把 all 拆给各销售 / 本周抽谁 / 劳务发票核对 / 九点下单 / 对比追觅进度。

## 斯佳

| 名称 | id | 简介 | 需要提供 |
|------|----|------|----------|
| 金蝶入账（斯佳） | kingdee-posting | 销项 / 付款 / 收款填引入表 | 三入口都要金蝶开放平台应用 ID/密钥。销项/收款另要金蝶网页账密（脚本自己引出客户核算项目余额表）。付款：台账 Excel + 发票 PDF。收款：中行收款 Excel；销售空了才要智云账号 |
| 月度损益表（斯佳） | pl-dept-report | 星辰拼损益表和利润表 | 金蝶网页账密 + 开放平台应用 ID/密钥。山东/四川/济南代账利润表 Excel。薪酬台账有就给 |
| 序时账入金蝶（斯佳） | kingdee-gl-import | 序时账转引入表 | Excel：序时账。不要账密 |
| 部门费用归集分摊（斯佳） | dept-expense-alloc | 用友按人拆部门费用 | Excel：用友余额表、收入底稿、人员归属、按人明细 |
| 合并报表（斯佳） | consolidated-statements | 八主体合并底稿 | 会计月份。从金蝶拉要网页账密。山东/四川/济南要人放报表 Excel |
| 代扣代缴申报表重命名（斯佳） | withholding-report-rename | 申报 PDF 改名 | PDF：申报表一夹。不要账密 |

开口：销项发票入金蝶 / 付款入金蝶 / 收款入金蝶 / 月度损益表 / 序时账入金蝶 / 部门费用归集 / 出合并报表 / 申报表重命名。

## 本机 json（按活分开）

| 活 | 只用 | 不要碰 |
|----|------|--------|
| 销项 / 付款入金蝶 | `kingdee.local.json`（开放平台应用 ID/密钥） | `zhiyun.local.json` |
| 收款入金蝶 | `kingdee.local.json`；销售空了才由 convert.py 读 `zhiyun.local.json` | 先手搓登录智云 |
| 月度损益表 | `kingdee.local.json` + `xingchen.local.json`（网页账密） | `zhiyun.local.json` |
| 出合并报表（从金蝶拉） | `xingchen.local.json` | 把 `kingdee.local.json` 当网页登录 |
| 序时账入金蝶 | 不用本机密钥 json | 金蝶入账、智云 |
| 九点下单 | 本技能 `config.local.json` 或智云账号密码 | 金蝶 json |
| 核销日清 | 核销自己的智云凭据 | 收款那份 `zhiyun.local.json` |
