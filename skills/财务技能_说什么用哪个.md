# 财务技能包 · 说什么用哪个

装进 opencode 后，agent 先用这张表认技能。同事不用记英文 id。

## 更新 / 安装（对接 Gitee）

对 opencode 说：

```
更新财务skills
```

同义：更新财务技能 / 更新技能包 / 拉最新 / 安装财务skills

- 源：Gitee `https://gitee.com/Lee157/finance-skills` 的 `main`（不通再 GitHub）
- 只覆盖官方白名单；本地 `config/` 默认保留（核销的业务规则跟仓库走）
- 核销已合入 main（李尚最新），更新时一并覆盖
- 白名单外她自己装的技能一律不删
- 更新完重启 opencode

## 业务活

| 启动时说（任选） | 技能 | 干什么 |
|------------------|------|--------|
| 跑本周应收 / 应收合并 / 做应收all | receivables-merge | 分年表合成应收 all |
| 把 all 拆给各销售 / 按销售拆分 | split-by-sales | 一人一份应收表 |
| 核对劳务发票 / 谁没开票不能付 | labor-invoice-check | 付款前对个人票 |
| 把这批申报表按公司名+金额重命名 | withholding-report-rename | 代扣代缴 PDF 改名 |
| 本周抽谁 / 合规抽查 | compliance-spot-check | 建议抽查名单 |
| 对比一下追觅这两版进度 | dreame-ar-progress-diff | 追觅进度 diff |
| 跑本月部门费用归集 / 用友部门费用归集 | dept-expense-alloc | 用友按人拆部门费用 |
| 月度损益表 / 科目余额表 / 出本月损益表 / 跑斯佳那张表 | pl-dept-report | 金蝶星辰拼损益表+利润表 |

| 销项发票入金蝶 / 付款入金蝶 / 收款入金蝶 / 琪哥发票入金蝶 | kingdee-posting | 三模块填金蝶引入表；科目/销售由智云补；旧「琪哥」仍进销项 |
