# 财务技能包 · 说什么用哪个

装进 opencode 后，agent 先用这张表认技能。同事不用记英文 id。

## 更新 / 安装（对接 Gitee）

对 opencode 说：

```
更新财务skills
```

同义：更新财务技能 / 更新技能包 / 拉最新 / 安装财务skills

- 源：Gitee `https://gitee.com/Lee157/finance-skills` 的 `main`（不通再 GitHub）
- 只覆盖官方白名单；本地 `config/` 默认保留（核销的业务规则跟仓库走）
- 核销已合入 main（李尚最新），更新时一并覆盖
- 白名单外她自己装的技能一律不删
- 已下线的 `env-doctor`（环境管家）更新时从本机删掉，不要再用
- 更新完重启 opencode

## 本机 json（按活分开，禁止串门）

| 她说的活 | 只用这些 | 不要碰 |
|----------|----------|--------|
| 销项发票入金蝶 / 付款入金蝶 | `~/.config/finance/kingdee.local.json` | `zhiyun.local.json`、`xingchen.local.json`、九点下单登录脚本 |
| 收款入金蝶 | `kingdee.local.json`；表上销售空了才由 **convert.py** 读 `zhiyun.local.json` | 你先手搓登录智云；把智云失败当成停表 |
| 月度损益表 | `kingdee.local.json` + `xingchen.local.json` | `zhiyun.local.json` |
| 序时账入金蝶 | 不用本机密钥 json | `kingdee-posting`、智云 |
| 九点下单 | 本技能 `config.local.json` 或 `ZHIYUN_USER` / `ZHIYUN_PASSWORD` | `kingdee.local.json`、`xingchen.local.json` |
| 核销日清 | 核销自己的凭据库 / `ZHIYUN_USER` + `ZHIYUN_PASS` | `kingdee.local.json`、收款那份 `zhiyun.local.json` 当入口 |

「不生成引入表」只适用于：没金蝶应用号、档案失败、凭证号查不到。**不适用于智云。**

## 缺库怎么装（不要另开技能）

不要对她说「配下环境」，也不要找环境管家。缺哪个库就在当前任务里装：

```
python3 -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <包>
```

清华失败换阿里 `https://mirrors.aliyun.com/pypi/simple`，再换中科大 `https://pypi.mirrors.ustc.edu.cn/simple`，镜像都失败再去掉 `-i` 走默认源。

对照：`docx`→`python-docx`，`pptx`→`python-pptx`，`PIL`→`Pillow`。不要 pip `validators` / `helpers` / `office`（技能自带模块）。LibreOffice / poppler / tesseract 见仓内 `docs/依赖安装.md`。
