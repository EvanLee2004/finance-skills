# 财务技能包 · 说什么用哪个

按使用人排。名称后括号是谁用。同事不用记英文 id。

源：Gitee `https://gitee.com/Lee157/finance-skills` 的 `main`。

## 亮晶

| 名称 | id | 简介 |
|------|----|------|
| 应收账款合并（亮晶） | receivables-merge | 分年表合成应收 all |
| 应收按销售拆分（亮晶） | split-by-sales | 一人一份应收表 |
| 合规文件抽查（亮晶） | compliance-spot-check | 建议抽查名单 |
| 劳务发票核对（亮晶） | labor-invoice-check | 有票 / 800 以下 / 无票 |
| 九点下单统计（亮晶） | order-daily-summary | 下单数据（万元） |
| 追觅应收进度对比（亮晶） | dreame-ar-progress-diff | 两版追觅进度差 |

开口：跑本周应收 / 把 all 拆给各销售 / 本周抽谁 / 劳务发票核对 / 九点下单 / 对比追觅进度。

## 明妹

| 名称 | id | 简介 |
|------|----|------|
| 应收核销日清（明妹） | ar-hexiao-daily | 出纳核销日清 |

开口：跑昨天的核销 / 日清 / 重扫挂账。

## 斯佳

| 名称 | id | 简介 |
|------|----|------|
| 金蝶入账（斯佳） | kingdee-posting | 销项 / 付款 / 收款填引入表 |
| 月度损益表（斯佳） | pl-dept-report | 星辰拼损益表和利润表 |
| 序时账入金蝶（斯佳） | kingdee-gl-import | 序时账转引入表 |
| 部门费用归集分摊（斯佳） | dept-expense-alloc | 用友按人拆部门费用 |
| 合并报表（斯佳） | consolidated-statements | 八主体合并底稿 |
| 代扣代缴申报表重命名（斯佳） | withholding-report-rename | 申报 PDF 改名 |

开口：销项发票入金蝶 / 付款入金蝶 / 收款入金蝶 / 月度损益表 / 序时账入金蝶 / 部门费用归集 / 出合并报表 / 申报表重命名。

## 通用

| 名称 | id | 简介 |
|------|----|------|
| Excel（通用） | xlsx | 改表 |
| Word（通用） | docx | 改 Word |
| PPT（通用） | pptx | 改 PPT |
| PDF（通用） | pdf | 处理 PDF |

缺库当场清华镜像装，不要另开技能。

## 本机 json（按活分开）

| 活 | 只用 | 不要碰 |
|----|------|--------|
| 销项 / 付款入金蝶 | `kingdee.local.json` | `zhiyun.local.json` |
| 收款入金蝶 | `kingdee.local.json`；销售空了才由 convert.py 读 `zhiyun.local.json` | 先手搓登录智云 |
| 月度损益表 | `kingdee.local.json` + `xingchen.local.json` | `zhiyun.local.json` |
| 出合并报表（从金蝶拉） | `xingchen.local.json` | 把 `kingdee.local.json` 当网页登录 |
| 序时账入金蝶 | 不用本机密钥 json | 金蝶入账、智云 |
| 九点下单 | 本技能 `config.local.json` 或 `ZHIYUN_USER` / `ZHIYUN_PASSWORD` | 金蝶 json |
| 核销日清 | 核销自己的凭据库 | 收款那份 `zhiyun.local.json` |
