# 智云核对

写在交给亮晶的同一个 Excel 里，sheet 名「智云核对」。不另出文件。

销售反馈里的客户都要查。登录和取数用这两条，不要另写：

```bash
python3 "<本skill目录>/scripts/probe_list.py" --sales <销售反馈绝对路径> --out <目录>/客户订单.tsv
python3 "<本skill目录>/scripts/zhiyun_probe.py" --customers <目录>/客户订单.tsv --out <目录>/智云核对.xlsx
```

`zhiyun_probe.py` 用 Playwright 打开智云，登录用本机已保存的亮晶账号（`~/.config/finance/zhiyun.local.json`）。密码不出现在对话、日志、仓库里。合同和下单是登录之后的只读查询。

打开应用「智云」，左侧「CMS/客户管理」→「合同管理」。单子在「订单 / 下单 / 订单明细」。合同在「合同」。合同表上能看到的列：客户、销售、合同名称、合同类型、合同金额、合同编号、签订日期、合同审批。合同类型里会有年度框架协议、项目制协议。

给她看的「智云核对」是销售反馈里一个单号一行，按销售、客户排在一起。合同归档号只写这个单挂上的那份；下单行上写了归档号、但没关联到合同记录时，用下单上的那个号。订单状态只写下单页那一列。没有就写未找到，这两格涂浅黄。两列都只有一个值时，说明留空。一张单挂了多份合同，或下单里有多个状态，说明里写明。不把没挂这个单的合同再开一行，也不写「看不出来」。没有本机登录就停下来问，不要空跑。不写回她的台账。

不要打开「回款记录」去核对销售说的已回款是不是真到账。
