# 应收抽查

亮晶每周从还挂着的应收里抽一批，向销售要盖章或对公邮件。你交回一个 Excel，五页：待抽查清单、建议本次抽、豁免与已回款、风险提示、智云核对。建议本次抽是这一期真正要看的结果。待抽查清单是底稿。原件不改，不写进她的台账，不发邮件。

## 做完是什么样

- 一个工作簿，五页：待抽查清单、建议本次抽、豁免与已回款、风险提示、智云核对。路径用大白话告诉她。五页不齐不要交。谁进建议本次抽、档怎么定、豁免关键词是什么意思，由你按 `references/判断.md` 写成 `判断.json`。脚本只筛选字段、把你的判断写回表格，不替你挑人，不替你定档。
- 旁边留着事实表，给你自己对证据，不叫她读。
- 台账里没写成 `202508` 这种的格子，出现在事实表的「待看」里，没有被当成每个月都查过。
- 同一个工作簿里有「风险提示」和「智云核对」。新闻每条有链接，或者写未查到。智云核对按销售反馈里的单号一行，写这张单的合同归档号和下单订单状态，没有就写未找到。
- 口头只说组数、路径、她要勾的草稿。不报客户全名，不报金额。

## 认文件

两张，看表头，不看文件名。

- 合规文件抽查待跟进：有抽查日期、交付月份、正式确认。
- 销售反馈应收：有交付月份、账龄、结算阶段、单号。

认不出就停，问她哪张是哪张。

## 先出事实，再下判断

```bash
python3 "<本skill目录>/scripts/prepare.py" --ledger <台账绝对路径> --sales <销售反馈绝对路径> --out <目录>/事实.xlsx
```

不指定角色时，把两个文件放在 `--inputs` 后面，脚本按表头认。

脚本只拆月份、把本期每一行对上台账里的原话。它不决定抽谁，不删人，不搜新闻，不登录。stdout 出现 `ask=`，先处理那一句再往下写。

月份只按 `scripts/months.py`：横线补满每个月，且结束月不晚于抽查月；顿号和逗号只留点到的月；写了年份的按原文。

事实表出来之后，你来判断，不要另写一套挑选脚本。读 `references/判断.md`，写出 `判断.json`，再交给 `compose.py` 落表。

`判断.json` 三块：

- `同一人`：名字不同但是同一个人的销售。`梁玲玲` 和 `梁玲玲-高美杰` 算一个人，算作「梁玲玲」。表上的销售格子仍写原名。
- `关键词`：豁免清单里每一行正式关键词都要有。你判断含义是「客户名称」还是「销售人员」。豁免原因照抄她的原话。写着「豁免口径」或「供参考」的，连同后面的行，不读，也不写进这个文件。
- `建议`：本周短名单。每一行有销售、客户、交付月份、档、原因。档只写高危、次危、信用期内但要看、补位。
- `订单状态核对`：智云订单状态和销售结算阶段两边都有字的单。核对只写「不冲突」或「不一致」。未找到、或一边是空的，不要写，脚本留空。

每个销售至少一条建议。同一人合并后再数。某人只剩已豁免、已拿到、坏账或两边都已回款时，不必硬塞一条。过不了金额线、又必须抽到的，档写补位，挑这个人最该看的一条。

销售结算阶段和智云订单状态两边都写了已回款，这是字段筛选，脚本来做，原因写「销售和智云都已回款」。已确认别名只在新闻里合成一行，不因此离开待抽。草稿没点头之前，不写已豁免，新闻也不并。

## 按步骤再读

事实表出来之后，新闻和智云都要做完，再把 Excel 给她。四页都在这一份工作簿里，不另给文件。

- 写新闻前读 `references/新闻.md`。每个客户一行 jsonl，字段 `customer`、`summary`、`url`、`note`。有链接再加 `risk` 和 `reason`。摘要可以沿用已经查到的新闻，不必重搜。`risk` 由你读摘要后按经营口径定成高、中、低或无。`reason` 写一句为什么。没查到的不用写原因。脚本只照抄，不按关键词改等级。
- 智云前读 `references/合同.md`。下面这两条就是登录和取数，不要另写一套。

```bash
python3 "<本skill目录>/scripts/probe_list.py" --sales <销售反馈绝对路径> --out <目录>/客户订单.tsv
python3 "<本skill目录>/scripts/zhiyun_probe.py" --customers <目录>/客户订单.tsv --out <目录>/智云核对.xlsx
```

抽查月用这期销售反馈的月份，写成 YYYYMM。`scripts/compose.py` 不决定抽谁，也不定档。它核对你的 `判断.json` 盖住了每个销售，再把你写的档和原因抄进表。

```bash
python3 "<本skill目录>/scripts/compose.py" --facts <目录>/事实.xlsx --news <目录>/新闻 --zhiyun <目录>/智云核对.xlsx --ledger <她正在用的台账绝对路径> --judgment <目录>/判断.json --check-month <YYYYMM> --retrieved <YYYY-MM-DD> --out <目录>/应收抽查.xlsx
```

交出去之前跑。退出码不是 0 就还没做完：

```bash
python3 "<本skill目录>/scripts/check_delivery.py" --workbook <交给她的xlsx绝对路径>
```

## 不要

- 不要另写一套月份拆法，也不要只留横线的头尾。
- 不要把微信对账、飞书对账、个人邮箱直接当成必抽，或当成已经通过。
- 不要拿智云去对银行流水或用友凭证。订单状态和销售结算阶段冲不冲突，由你写进判断.json。脚本只把「不一致」标红。没核到的留空。
- 不要把客户全名和金额写进对话。
