# 合并报表

把八个主体当月的资负 / 利润 / 现金流合成一份底稿（明细为数、合计为公式），再拆出合并分册和母公司分册。

## 你给什么

- **必给**：会计月份，如 `202608`。
- **可选**：一个文件夹，里面是各公司已导出的 xlsx。山东 / 四川 / 济南没有金蝶自动拉，要人放表。
- **可选**：说「从金蝶拉」→ 脚本只拉五个星辰账套（本部、文化、上海、湖南分、湖南科技）。账密只读 `~/.config/finance/xingchen.local.json`（与月度损益表同一份）。没有这份文件就停，问她去写，禁止在对话里要密码。

## 就跑这一条

```bash
python3 "<本skill目录>/scripts/entry.py" --period YYYYMM --input-dir <报表夹绝对路径> --out-dir <交付夹>
```

要从金蝶拉再加 `--fetch-kingdee`。缺库当场清华镜像装 `openpyxl`；拉表还要 `playwright`。不要另开环境管家。

## 红线

1. 禁止自写 Python 读她的表。只准调本技能 `scripts/entry.py`。
2. 禁止点金蝶「引入 / 审核 / 过账」，禁止解绑总部。
3. 对话只报期间、文件个数、路径、warnings 条数。禁止报金额明细和客户名。
4. 金蝶取数失败 → 停，把 `ask=` / warnings 原样告诉她；不要猜科目。

## 收尾

- *「YYYYMM 合并底稿在 \<路径\>。完整/部分/待核实见文件名。我没有点引入。」*
- 山东、四川、济南没表会出部分底稿，提醒她补文件再跑。
