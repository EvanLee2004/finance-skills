逻辑一变，同一个 commit 改：脚本 + 测试 + `README.md` 的 Mermaid + 本文件（若步骤变了）。

## 软件工程（本工作区强制）

1. 新口径先 Spec Kit：销项科目以 `specs/015-kingdee-sales-assist-copy/` 为准。禁止脑补科目。
2. 写码节奏：想清楚 → 设计（本技能无 UI 可记一笔跳过）→ 脚本算钱 → 删冗余 → pytest。
3. 金额只脚本算；禁止 agent 自写 Python 读真表。
4. 真票 / 真台账 / 密钥不进 `finance-skills`（公开仓）。见仓内 `docs/仓库边界_什么进什么不进.md`。
5. 判绿：`命令; echo EXIT:$?`，禁止 `| tail` / `| head`。
6. 工位：复用 `finance-skills` 正式 clone 的 `main`，禁止盲开第二间 worktree。
7. 测绿后才 commit；**push / 部署须明昊确认**。
8. 同事更新：push 了 ≠ 本机已更新。她要说「更新财务skills」。本技能必须在 `update-finance-skills/config/pack.json` 白名单里。
9. 旧销项 `qige-invoice-to-kingdee` 只作兼容触发，口径以本技能为准；不要删它的测试。
10. 李尚核销合入只动 `skills/ar-hexiao-daily/`；金标若与本地真表差 2 笔，记 progress，不改他的规则凑绿。
