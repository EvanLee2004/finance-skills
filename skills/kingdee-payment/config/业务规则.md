# 供应商付款入金蝶 · 业务规则

数字以同夹 `rules.json` 为准。斯佳 2026-09-17 当面；银行科目用亮晶号现网 记-75 核对。

## 材料

- 外面一张三列表：供应商 / 应付金额本币 / 开户名。
- 一家一个夹，夹里只读发票 PDF。夹里别人的 Excel 当没看见。
- 不要去服务器取票。

## 分录

- 专票：借 `540103`（应付−进项）+ `21710101`（票面税额） / 贷银行（应付）
- 普票：借 `540103` 全额 / 贷银行（应付）
- 成本挂供应商 + 部门 `0405` + 职员「项目总监」（现网编码 113）。进项、银行不挂。
- 摘要 `付：{发票销售方名称}`，不去掉「（个体工商户）」

## 银行（填色，听明妹）

- 供应商或应付标黄 → 中行 `100201`（中行宣武门支行1001）
- 没颜色 → 中信 `100206`（中信银行广安门支行）
- 现网 2026-08 记-75：75 笔中信 100206、5 笔中行 100201。跑批前 Playwright 登总部核这两个科目还在。

## 供应商

- 模糊找。一对多 → `9999` 其他供应商。
- 档案没有的（标黄走中行、没标黄走中信）**一次问斯佳**，两路分开写名字。不要只问标黄、把中信偷偷挂 9999。
- 她说中行新建 → `--create-new-suppliers`（现网 3～4 位编号 max+1，排除 9999）。
- 她说中信挂其他供应商 → `--citic-as-other`。
- 她说中信也新建 → `--create-new-suppliers-citic`。

## 金额

- 一家多张票，价税合计对这一行应付。
- 票 < 应付 → 待确认，不要猜。
- 票 > 应付 → 一批问一次：是否一律按应付记。是则 `--book-short-pay`。否就停着等她口头改。
- 票 = 应付 → 直接记。

## 记账日 / 凭证号

- 记账日 = 当前月金蝶最后一张凭证的日期（没凭证才今天）。
- 凭证号没说 = 当月最大 + 1，一家一记。查询失败整批停。

## 产出

桌面 `金蝶入账_付款_YYYYMMDD/`：引入表 + 明细 + 对照说明。人过目后自己去金蝶点引入。不点引入、审核、过账。
