# 供应商付款入金蝶 · 业务规则

数字以同夹 `rules.json` 为准。斯佳 2026-09-17 当面；银行科目用亮晶号现网 记-75 核对。

## 材料

- 外面一张三列表：供应商 / 应付金额本币 / 开户名。
- 一家一个夹，夹里只读发票 PDF。夹里别人的 Excel 当没看见。
- 不要去服务器取票。

## 分录

- 专票：借 `540103`（应付−进项）+ `21710101`（票面税额） / 贷银行（应付）
- 普票：借 `540103` 全额 / 贷银行（应付）
- 成本挂供应商 + 部门 `0405` + 职员「项目总监」（现网编码 113）。进项、银行不挂。
- 摘要 `付：{发票销方（开票抬头）公司名}`。票面原样：括号统一全角、去掉票面断字空格、保留「（个体工商户）」。
- **禁止**把摘要写成我方购买方名，也**禁止**用台账「开户名」列或夹里的人名代替。抽不到 → 待确认。

## 银行（填色，听明妹）

- 供应商或应付标黄 → 中行 `100201`（中行宣武门支行1001）
- 没颜色 → 中信 `100206`（中信银行广安门支行）
- 现网 2026-08 记-75：75 笔中信 100206、5 笔中行 100201。跑批前 Playwright 登总部核这两个科目还在。

## 供应商

- **找档与新建一律按发票销方（开票抬头）公司名**（斯佳 2026-09-21）。台账「供应商」列在个人转对公时写的是人名（「胡继成」这种），**不参与匹配**；发票名找不到就按下面的金额规则走，不许静默挂回人名档案。
- 模糊找。一对多 → `9999` 其他供应商。
- **找不到档时按金额分流**（斯佳 2026-09-21）：
  - 应付 **< 30000** → 直接记 `9999` 其他供应商，**不问**；在明细表「原因」列标出「缺档→其他供应商 9999（自动：应付 < 30000）」。
  - 应付 **≥ 30000** → 待确认，**先问她是否新建**；问的时候报**发票公司名**，不报台账里的人名。
  - 阈值在 `rules.json` 的 `auto_other_supplier_below`；临时可用 `--auto-other-below N` 覆盖。
- **新建名 = 发票里的公司名原样**（不带括号里的人名／「（个人团体）」这类备注；票面自带的「（个体工商户）」「（个人独资企业）」保留）。
- 她说新建 → `--create-new-suppliers`（现网 3～4 位编号 max+1，排除 9999）。
- `--citic-as-other` / `--boc-as-other` **已废弃**（缺档按金额自动分流），传了不起作用。

## 金额

- 一家多张票，价税合计对这一行应付。
- 票 < 应付 → 待确认，不要猜。
- 票 > 应付 → 一批问一次：是否一律按应付记。是则 `--book-short-pay`。否就停着等她口头改。
- 票 = 应付 → 直接记。

## 记账日 / 凭证号

- 记账日 = 当前月金蝶最后一张凭证的日期（没凭证才今天）。
- 凭证号没说 = 当月最大 + 1。**本批全部合一张凭证（所有行同一个号）**——斯佳 2026-09-21 定。要一家一张加 `--one-voucher-per-payee`。查询失败整批停。

## 产出

桌面 `金蝶入账_付款_YYYYMMDD/`：引入表 + 明细 + 对照说明。人过目后自己去金蝶点引入。不点引入、审核、过账。
