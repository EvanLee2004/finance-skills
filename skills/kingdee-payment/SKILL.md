# 供应商付款入金蝶

每月供应商付款入账。金额、科目、银行、档案由脚本确定性计算；模型只负责找文件夹、跑命令、把 `ask=` 原样转述给需求方。绝不点引入 / 审核 / 过账。

后台与示意图：同夹 `README.md`。口径正本：同夹 `config/业务规则.md`。

## 0. 本机 json

只用 `~/.config/finance/kingdee.local.json`（金蝶开放平台应用号）。

**不登金蝶网页**（2026-09-21 起去掉那一步）：银行科目、供应商档案、凭证号三样全部走应用号。
网页账密 `~/.config/finance/xingchen.local.json` 属于销项/收款与损益表技能，本技能不看、不问、不依赖。

禁止：把口令写进对话；去开放平台点重置密钥；用 `zhiyun.local.json`。
本机已有 `kingdee.local.json`，不要再问密码。

## 1. 红线

1. 只调本技能 `scripts/convert.py`，不要自写 Python 读需求方的台账。
2. 发票夹里的 Excel 一律忽略，只读 PDF。
3. **摘要 = `付：` + 发票销方（开票抬头）公司名**。抽不到就判待确认，不许拿我方购买方名或台账「开户名」凑。
4. **找档与新建一律按发票销方公司名**。台账「供应商」列在个人转对公时写的是人名（如「胡继成」），**不参与匹配**；发票名找不到就判缺档问她，不许静默挂回人名档案。
5. **新建供应商名 = 发票里的公司名原样**：去掉括号里的人名、「（个人团体）」「（XX团队）」这类备注；票面自带的「（个体工商户）」「（个人独资企业）」**保留**。
6. 禁止编供应商编码。缺档（标黄走中行、没标黄走中信）**一次问清**，两路分开写名字，报的是**发票公司名**。
7. 禁止点金蝶「开始引入 / 审核 / 过账」。账套用总部，不要湖南分公司。
8. 票大于应付：一批只问一次是/否，不要一家一家问。
9. **凭证号：本批全部合一张凭证**（所有行同一个号 = 当月最大 + 1）。要一家一张才加 `--one-voucher-per-payee`。

## 2. 找文件夹

```bash
python3 "<本skill目录>/scripts/convert.py" --inspect --input-dir <绝对目录>
```

缺件退出非 0，stdout 有 `ask=`，原样转述。台账放在发票夹外面，一家一个发票夹。

## 3. 跑转换

```bash
python3 "<本skill目录>/scripts/convert.py" --input-dir <绝对目录>
```

系统 python3 缺库时脚本会切仓内 `.venv`。未指定输出目录 → 桌面 `金蝶入账_付款_YYYYMMDD/`。

- 她点头「按应付记」→ 加 `--book-short-pay` 重跑。
- 缺档一次问：标黄（中行）建不建、没标黄（中信）新建还是挂 9999。
  - 中行新建 → `--create-new-suppliers`
  - 中信挂 9999 → `--citic-as-other`
  - 中信也新建 → `--create-new-suppliers-citic`
- 她点名凭证号从 N 起 → `--start-voucher-no N`；点名日期 → `--date`。
- 要一家一张凭证 → `--one-voucher-per-payee`。
- `--skip-browser` 已废弃（不再登网页），传了也不起作用。

**表出完尽快引入。** 凭证号是「跑的那一刻」查的；隔久了别人又录凭证会占号 → 重跑取最新号，不要直接用旧表。

## 4. 收尾

- *「这批 N：可入账 X，待确认 Y，合 <k> 张凭证（号 <v>）。表在 \<路径\>。请看待确认，再自己去金蝶引入。我没有点引入。」*
- 待确认只报原因类别和笔数。缺档必须把 `ask=` 原样转告：标黄（中行）一列、没标黄（中信）一列，一次拍板。金额不要报。
- **看两处自检**（跑完的 stdout 会提示，明细在对照说明里）：
  1. 摘要逐眼看：出现我方公司名或夹里人名 → 销方抽错，别交表。
  2. 「档案名自检」段：若列出 N 家**档案名与发票名不一致**（档案名里多了括号备注），表已按发票名挂对，但要提醒需求方去金蝶改档案名；下次重跑前若已改完，这一段会自动消失。

## 5. 会变的在哪

| 文件 | 改什么 |
|------|--------|
| `config/rules.json` | 成本/进项/中行/中信/0405 |
| `config/业务规则.md` | 摘要口径、供应商挂档与新建口径、凭证号策略 |
| `config/列名别名.json` | 台账表头别名 |
| `config/凭证引入空模.xlsx` | 金蝶换官方模板时整份替换 |
| 本机 `kingdee.local.json` | 开放平台密钥；不进仓 |

## 该主动操心啥

- 标黄却走了中信、没色却走了中行 → 填色没读到，停。
- 摘要里出现我方公司名或夹里人名 / 开户名 → 销方抽错，停，别交表。
- 供应商档案名与发票名不一致 → 表能交，但要在收尾里点名提醒需求方改档案。
- 专票进项抽不到 → 待确认，不要用税率倒挤。
- 标题带空格的电子票（「专 用 发 票」）必须能认。
- 夹里突然又出现别人的 xlsx → 当没看见。
- 表在桌面放久了才引入 → 先重跑确认凭证号没被别人占。
